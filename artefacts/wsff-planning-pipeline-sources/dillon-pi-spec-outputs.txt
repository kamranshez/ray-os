## 1. Route the Link Catalog through its Durable Object

**Recommendation strength:** Strong  
**Category:** ports & adapters

**Files**
- `apps/mulroy.link/link-manager/src/index.ts`
- `apps/mulroy.link/link-manager/src/services.ts`
- `apps/mulroy.link/link-manager/src/link-catalog/LinkCatalogDurableObject.ts`
- `docs/adr/0001-effect-rpc-over-durable-object-fetch.md`

**Problem**  
The Link Catalog interface says Durable Object, but production composition uses an in-memory implementation and the Durable Object is effectively bound but not called.

**Solution**  
Make the Worker’s Link Catalog adapter call the named Durable Object over ADR-owned Effect RPC `fetch`, while tests keep a memory adapter at the same seam.

**Benefits**
- **locality:** deployment truth in one module
- **leverage:** one Link Catalog interface
- tests hit deployed seam
- ADR stops drifting

**ADR conflict**  
Current code exposes Alchemy RPC methods on the Durable Object, while ADR-0001 says Effect RPC over Durable Object `fetch`. This is worth reopening or enforcing because the Worker path currently bypasses the Durable Object entirely.

## 2. Deepen the Alias mutation module

### Current shallow seam

```ts
type LinkCatalogStore = {
  createAlias(input): Effect<AliasMutation, StoreWriteError | SlugConflictError>
  retargetAlias(input): Effect<AliasMutation, StoreWriteError | LinkNotFoundError>
  rollbackAliasMutation(mutation): Effect<void, StoreRollbackError>
}
```

Caller must know:

```ts
const mutation = yield* store.createAlias(input)

if (mutation.outcome === "changed") {
  yield* redirectIndex.putDestination(...)
    .pipe(Effect.catch(() => store.rollbackAliasMutation(mutation)))
}
```

That means rollback and Public Redirect Index ordering leak across the seam.

### Deeper module

```ts
type LinkCatalogMutations = {
  createAlias(input: CreateAliasInput): Effect<
    { outcome: "created" | "unchanged"; alias: AliasLink },
    SlugConflictError | AliasMutationError
  >

  retargetAlias(input: RetargetAliasInput): Effect<
    { outcome: "retargeted" | "unchanged"; alias: AliasLink },
    LinkNotFoundError | AliasRequiredError | AliasMutationError
  >
}
```

### Implementation owns internals

```ts
const makeLinkCatalogMutations = ({
  store,
  redirectIndex,
  lock,
}: {
  store: SqlLinkCatalogStore
  redirectIndex: PublicRedirectIndex
  lock: Semaphore
}): LinkCatalogMutations => ({
  createAlias: (input) =>
    lock.withPermits(1)(
      store.transaction(
        Effect.gen(function* () {
          const mutation = yield* store.createAliasRow(input)
          if (mutation.outcome === "unchanged") {
            return { outcome: "unchanged", alias: mutation.current }
          }

          yield* redirectIndex.putDestination(
            mutation.current.slug,
            mutation.current.destination,
          ).pipe(
            Effect.catch((cause) =>
              store.restoreAliasMutation(mutation).pipe(
                Effect.andThen(Effect.fail(new AliasMutationError({ cause }))),
              ),
            ),
          )

          return { outcome: "created", alias: mutation.current }
        }),
      ),
    ),
})
```

### Callstack

```ts
Durable Object RPC
  -> LinkCatalogMutations.createAlias
    -> lock
    -> SQL Store mutation
    -> Public Redirect Index write
    -> rollback/repair on failure
```

### Deepening

`AliasMutation` becomes an implementation detail, not part of the Store-facing caller interface.

### Mutation result carries explicit compensation

```ts
type InsertAliasResult =
  | {
      outcome: "inserted"
      alias: AliasLink
      compensate: "delete_inserted_alias"
    }
  | {
      outcome: "unchanged"
      alias: AliasLink
    }

  | {
      outcome: "updated"
      previous: AliasLink
      alias: AliasLink
      compensate: "restore_previous_alias"

  | {
      outcome: "unchanged"
      alias: AliasLink
    }
```

### Deep mutation module using services

```ts
export class LinkCatalogMutations extends Context.Service<LinkCatalogMutations, {
  createAlias(input: CreateAliasInput): Effect<
    { outcome: "created" | "unchanged"; alias: AliasLink },
    SlugConflictError | AliasMutationError
  >

  retargetAlias(input: RetargetAliasInput): Effect<
    { outcome: "retargeted" | "unchanged"; alias: AliasLink },
    LinkNotFoundError | AliasRequiredError | AliasMutationError
  >
}>()("link-manager/LinkCatalogMutations") {
  static readonly layer = Layer.effect(
    LinkCatalogMutations,
    Effect.gen(function* () {
      const lock = yield* Semaphore.make(1)

      return LinkCatalogMutations.of({
        createAlias: (input) =>
          lock.withPermits(1)(createAliasWorkflow(input)),

        retargetAlias: (input) =>
          lock.withPermits(1)(retargetAliasWorkflow(input)),
      })
    }),
  )
}
```

### Workflows use `yield* Service`

```ts
const createAliasWorkflow = Effect.fn("createAliasWorkflow")(function* (
  input: CreateAliasInput,
) {
  const store = yield* LinkCatalogStore
  const index = yield* PublicRedirectIndexService

  const result = yield* store.insertAlias(input)

  if (result.outcome === "unchanged") {
    return { outcome: "unchanged" as const, alias: result.alias }
  }

  yield* index.putDestination(result.alias.slug, result.alias.destination).pipe(
    Effect.catch((cause) =>
      store.deleteAlias(result.alias.slug).pipe(
        Effect.andThen(
          Effect.fail(new AliasMutationError({
            operation: "create_alias",
            slug: result.alias.slug,
            destination: result.alias.destination,
            cause,
          })),
        ),
      ),
    ),
  )

  return { outcome: "created" as const, alias: result.alias }
})

const retargetAliasWorkflow = Effect.fn("retargetAliasWorkflow")(function* (
  input: RetargetAliasInput,
) {
  const store = yield* LinkCatalogStore
  const index = yield* PublicRedirectIndexService

  const result = yield* store.updateAliasDestination(input)

  if (result.outcome === "unchanged") {
    return { outcome: "unchanged" as const, alias: result.alias }
  }

  yield* index.putDestination(result.alias.slug, result.alias.destination).pipe(
    Effect.catch((cause) =>
      store.restoreAliasSnapshot(result.previous).pipe(
        Effect.andThen(
          Effect.fail(new AliasMutationError({
            operation: "retarget_alias",
            slug: result.alias.slug,
            destination: result.alias.destination,
            cause,
          })),
        ),
      ),
    ),
  )

  return { outcome: "retargeted" as const, alias: result.alias }
})
```

```ts
Durable Object RPC

      -> putDestination
    -> on failure:
      -> deleteAlias
```

```ts

  sql: `INSERT INTO links (...) VALUES (...)`,
  bindings: [
```

### Store implementation uses `yield* LinkCatalogSqlExecutor`

```ts
const selectAliasLink = Effect.fn("selectAliasLink")(function* (slug: LinkSlug) {
  const sql = yield* LinkCatalogSqlExecutor

  const row = yield* sql.one(SelectAliasBySlug(slug))
  return Option.map(row, aliasLinkFromRow)
})

const insertAlias = Effect.fn("insertAlias")(function* (
  input: InsertAliasInput,
) {
  const sql = yield* LinkCatalogSqlExecutor

  return yield* sql.transaction(
    Effect.gen(function* () {
      const existing = yield* selectAliasLink(input.slug)

      if (Option.isSome(existing)) {
        if (existing.value.destination === input.destination) {
          return {
            outcome: "unchanged" as const,
            alias: existing.value,
          }
        }

        return yield* new SlugConflictError(input.slug)
      }

      const operatorId = yield* insertOrSelectOperator(input.operator)
      const now = yield* nowIso

      yield* sql.run(InsertAlias({
        slug: input.slug,
        destination: input.destination,
        createdAt: now,
        updatedAt: now,
        createdByOperatorId: operatorId,
        updatedByOperatorId: operatorId,
      }))

      const alias = yield* selectRequiredAliasLink(input.slug)

      return {
        outcome: "inserted" as const,
        alias,
        compensate: "delete_inserted_alias" as const,
      }
    }),
  )
})
```

# 5. `LinkCatalogCoordinator`

Owns:
- mutation serialization
- Store write ordering
- Public Redirect Index write ordering
- explicit compensation

```ts
export class LinkCatalogCoordinator extends Context.Service<LinkCatalogCoordinator, {
  createAlias(input: CreateAliasInput): Effect.Effect<
    AliasLink,
    SlugConflictError | LinkCatalogCoordinationError
  >

  retargetAlias(input: RetargetAliasInput): Effect.Effect<
    AliasLink,
    LinkNotFoundError | AliasRequiredError | LinkCatalogCoordinationError
  >
}>()("link-manager/LinkCatalogCoordinator") {
  static readonly layer = Layer.effect(
    LinkCatalogCoordinator,
    Effect.gen(function* () {
      const lock = yield* Semaphore.make(1)

      return LinkCatalogCoordinator.of({
        createAlias: (input) => lock.withPermits(1)(createAliasCoordination(input)),
        retargetAlias: (input) => lock.withPermits(1)(retargetAliasCoordination(input)),
      })
    }),
  )
}
```

## Create Alias coordination

```ts
const createAliasCoordination = Effect.fn("createAliasCoordination")(function* (
  input: CreateAliasInput,
) {
  const store = yield* LinkCatalogStore
  const index = yield* PublicRedirectIndexService

  const alias = yield* store.insertAlias(input)

  return yield* index.putDestination(alias.slug, alias.destination).pipe(
    Effect.as(alias),
    Effect.catch((cause) =>
      store.deleteAlias(alias.slug).pipe(
        Effect.andThen(
          Effect.fail(new LinkCatalogCoordinationError({
            operation: "create_alias",
            slug: alias.slug,
            destination: alias.destination,
            cause,
          })),
        ),
      ),
    ),
  )
})
```

## Retarget coordination

```ts
const retargetAliasCoordination = Effect.fn("retargetAliasCoordination")(function* (
  input: RetargetAliasInput,
) {
  const store = yield* LinkCatalogStore
  const index = yield* PublicRedirectIndexService

  const previous = yield* store.getAlias(input.slug)
  const alias = yield* store.updateAliasDestination(input)

  return yield* index.putDestination(alias.slug, alias.destination).pipe(
    Effect.as(alias),
    Effect.catch((cause) =>
      store.replaceAlias(previous).pipe(
        Effect.andThen(
          Effect.fail(new LinkCatalogCoordinationError({
            operation: "retarget_alias",
            slug: alias.slug,
            destination: alias.destination,
            cause,
          })),
        ),
      ),
    ),
  )
})
```

Callstacks:

```ts
createAlias
  -> store.insertAlias
  -> index.putDestination
  -> on index failure: store.deleteAlias
```

```ts
retargetAlias
  -> store.getAlias
  -> store.updateAliasDestination
  -> index.putDestination
  -> on index failure: store.replaceAlias(previous)
```

```ts
  const row = yield* sql.one(SelectAliasBySlug(slug))
  return Option.map(row, aliasLinkFromRow)
})
```

## 8. Final call graph

Production:

```ts
HTTP handlers
  -> LinkCatalog
    -> LinkCatalog.layerDurableObject
      -> Effect RPC over Durable Object fetch
        -> LinkCatalog.layer
          -> LinkCatalogCoordinator
            -> LinkCatalogStore
              -> LinkCatalogSqlExecutor
            -> PublicRedirectIndexService
```

Tests:

```ts
HTTP handlers
  -> LinkCatalog
    -> linkCatalogMemoryLayer
      -> LinkCatalog.layer
        -> LinkCatalogCoordinator
          -> LinkCatalogStore.layerMemory
          -> PublicRedirectIndexService.layerMemory
```

Depth wins:
- `LinkCatalog` is the stable test surface.
- `LinkCatalogCoordinator` owns cross-module ordering.
- `LinkCatalogStore` is CRUD-shaped.
- `LinkCatalogSqlExecutor` owns SQL and transaction mechanics.
- Durable Object integration becomes real production composition.
