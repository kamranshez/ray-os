DEEP DIVE
Three paths, one tool
SendMessage looks at the target's current state and picks a dispatch. The `to:` argument does not change; the behavior does.

Worker is busy

Task is still running. Your message lands in pendingMessages and is delivered on the next tool round, prefixed with "The coordinator sent a message while you were working:".

QUEUED

Worker clocked out

Task entry exists but status is completed, stopped, or failed. resumeAgentBackground() reads the transcript from disk and relaunches the agent under the same agentId.

RESUMED

Task evicted, transcript remains

The in-memory task entry is gone (cleanup, eviction, session age), but the JSONL transcript is still on disk. Claude rebuilds the agent from that file and relaunches under the same agentId.

REHYDRATED
Key insight: the caller never decides which path to use. The dispatch is automatic, driven by whatever the task registry says about the target.

DEEP DIVE
Resurrecting a stopped agent
Path 2: the transcript file is the seed. Same agentId gets a fresh query run, picking up everything the agent already knew.
resumeAgentBackground() reads the JSONL transcript, reloads the agent definition from a sidecar, rebuilds the tool list, appends your new message, then relaunches under the same ID. The delta in tokens proves it is one continuous session.

Two worlds: local vs team
SendMessage tries the local agent dispatch first. If the name is not in the registry, it falls through to the legacy team inbox (swarm mode).
Same input, two totally different plumbing systems. Local path is in-memory task manipulation. Team path is file-based mailboxes under ~/.claude/teams/.

LOCAL AGENT ROUTE 1. look up name agentNameRegistry.get(to) 2. check task state appState.tasks[agentId] 3. dispatch running → queuePendingMessage() stopped → resumeAgentBackground() no task → resumeAgentBackground()
TEAM INBOX ROUTE 1. check team context teamContext.teamName required 2. write mailbox file ~/.claude/teams/<team>/ inboxes/<recipient> 3. broadcast variant to: "*" writes to every teammate's inbox (team mode only, linear cost)
