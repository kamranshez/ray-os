### SUMMARY
Dex and Vaibhav (BoundaryML) demonstrate structured streaming patterns for AI applications, building generative UIs with BAML that incrementally render partial JSON safely.

### IDEAS
- Streaming partial JSON objects unlocks UX patterns impossible with traditional request-response LLM call patterns today.
- ChatGPT shows thinking tokens deliberately so users feel progress and stay engaged longer waiting.
- No website ever stops optimizing load time because perceived speed determines whether users actually stay.
- The fastest possible response would have the answer cached locally before the user even types.
- Network calls are inherently slow, so streaming visible progress beats waiting for complete responses always.
- Bad incremental UX causes users to bail early like aborting Claude Code on wrong thoughts.
- Cursor lets users checkpoint code and rewind, which compensates somewhat for poor incremental steerability.
- Markdown streams naturally token-by-token, but structured outputs need careful per-field streaming controls.
- Interactive components like serving sliders can compute live against still-streaming partial recipe data objects.
- Adding a few type annotations gives developers control over exactly when fields appear in UI.
- Numbers should not stream digit-by-digit because intermediate values are wildly wrong on charts.
- Graph axes snap incorrectly when partial numbers stream, making rendering jarring and visually confusing.
- BAML uses heuristics on field grammar to know when a number token sequence is complete.
- A UX slider exists between full token streaming and waiting for the complete response.
- Showing nothing until done feels slow; showing everything feels like every other AI app.
- Differentiation in AI applications today comes primarily from UX choices around streaming behavior.
- Building reactive components requires extensive null checks unless types reflect streaming completion guarantees clearly.
- Declarative streaming constraints in class definitions beat imperative conditional checks scattered through render code.
- BAML codegens React hooks and server actions automatically from your declared function definitions.
- Partial streaming returns full incrementally-updated objects, not token diffs, simplifying reactive component code.
- Users can edit streaming output mid-flight, replacing chicken breast 500g with one breast immediately.
- Long async workflows of 5-8K tokens before user interaction basically become tab-and-come-back experiences.
- Items emitted from streaming arrays can kick off downstream parallel workflows immediately, slashing latency dramatically.
- Coding agents fundamentally do structured outputs streaming, with tools, thinking, and progress all visible.
- Making LLMs generate React components from inferred schemas creates dynamic-but-stable rendering pipelines.
- Two-model setups separate data generation from rendering, enabling cached UI templates for repeated queries.
- Design systems can constrain AI-generated UI to match brand themes using component libraries.
- Streaming does not optimize tokens; it lets you spend more without forcing user wait.
- Bidirectional streaming requires interrupting at the right moment to inject new steering information.
- Sensitive fields like passwords need special handling to avoid leaking data mid-stream as text.
- Stream cancellation is the only real way to retract content already partially generated by models.
- Asterisks rendering before markdown bold formatting completes is jarring and could be hidden gracefully.
- Type-safe streaming means UI components receive guaranteed-complete fields without optional null guards everywhere.
- Adding interactivity earlier in long generations transforms async workflows into engaged real-time experiences.
- Whether schemas come from JSON Schema, Zod, or BAML matters less than having one.

### ONE-SENTENCE TAKEAWAY
Encode streaming completion semantics in your type system so generative UIs render safely without imperative null-checks.

### RECOMMENDATIONS
- Annotate which fields must complete before streaming so UI never renders partial unusable garbage states.
- Use full streaming for long-form text but item-complete streaming for arrays and structured fields.
- Mark numbers as completion-only to prevent jarring digit-by-digit rendering on charts and graphs.
- Reflect your UX intent in the type system rather than scattering conditional checks through render code.
- Add edit affordances next to streaming fields so users can correct values before generation completes.
- Kick off downstream parallel work the moment each array item completes rather than waiting for full response.
- Treat agent tool calls as structured output streams and design their UI accordingly with progress indicators.
- Generate React components from inferred schemas using a second model for dynamic-but-stable rendering pipelines.
- Constrain AI-generated UI to your existing design system components to maintain brand consistency automatically.
- Cancel streams via interruption logic when content drifts into invalid territory mid-generation reliably.
- Hide sensitive fields like passwords until completion to prevent partial-data leaks during streaming output.
- Mask markdown formatting tokens like asterisks until the full styled element resolves cleanly visually.
- Choose your streaming granularity per field deliberately based on user-experience trade-offs not defaults.
- Build interactive sliders and inputs that compute live against partial streaming data for engagement boosts.
- Use BAML codegen hooks rather than hand-rolling streaming state management code in every component.
- Watch episode 19 of AI That Works for bidirectional streaming and interruption pattern details.
- Push code changes after demos so the community can submit PRs improving rough examples.
- Keep state outside the streaming object so user edits persist across incoming token updates correctly.
- Test streaming behavior with deliberately weak models to surface edge cases your strong models hide.
- Submit topic ideas to the AI That Works GitHub repository to shape future episodes meaningfully.
