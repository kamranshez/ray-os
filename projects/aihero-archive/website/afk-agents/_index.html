    Day 5 AFK Agents

    Set up safe HITL and AFK agent workflows that can pull from GitHub issues, work in sandboxes, and ship backlog tasks while you keep control of the process.

    Matt Pocock
    Content

    Day 5 is about AFK agents: when to let an agent work more independently, when not to, and how to keep the work bounded. You will set up safer agent workflows around sandboxes, backlogs, GitHub issues, and repo tasks.

    What you will learn

    • What AFK agents are and where they fit
    • How sandboxing changes the risk profile
    • How HITL and AFK workflows differ
    • How to set up and try AFK agents
    • How to queue work through backlogs and GitHub issues
    • How to connect agents to repo tasks without giving up review
