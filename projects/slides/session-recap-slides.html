The Prompt
A single constant, MP1. No template, no variables, no context injection.
The model already has the full conversation in cache. All the prompt has to do is say “summarise it for the returning user”.
binary · MP1
// verbatim constant from the bundle The user stepped away and is coming back. Recap in under 40 words, 1-2 plain sentences, no markdown. Lead with the overall goal and current task, then the one next action. Skip root-cause narrative, fix internals, secondary to-dos, and em-dash tangents.
