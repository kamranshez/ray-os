Catalogue of hidden, gated, and unreleased features in Claude Code **v2.1.207** (build `bc512d5`, 2026-07-10), extracted from the shipped binary via the binary-explorer skill on 2026-07-12. Six parallel subagents swept the flag registry, gating predicates, slash commands, env/settings, tools/prompts, and models/endpoints/daemon.

## How gating works in this build

The old `tengu-<name>` Statsig gates are gone. Flags now read through **GrowthBook** helpers (minified names in parens):

- `Qe(key, default)` = getFeatureValue — `default=!1` (false) means OFF until Anthropic flips it server-side.
- `w1(key)` / `Ype(key)` = getDynamicConfig (stale-cached / blocks-on-init).
- `uG(key)` = checkGate.
- Predicate `return !1` (hardcoded false) = **deepest dark** — not even server-flippable yet.
- `function X(){ return Qe("tengu_...", false) || be.CLAUDE_CODE_... }` — the env var is the **local override** that force-unlocks a server-gated feature.
- **`CLAUDE_INTERNAL_FC_OVERRIDES`** = JSON blob that overrides ANY GrowthBook flag locally. The skeleton key.

Flag keys are deliberately obscured colour codenames (`tengu_amber_anchor`, `tengu_copper_lantern`, `tengu_velvet_ibis`…). ~200 are opaque A/B buckets with no self-describing meaning; the ones that map to real features are below.

## 1. Fleet — background-agent orchestration (the headline)

The largest unreleased surface: a **coordinator** session that spawns **worker** subagents, a `FleetView` TUI, and a persistent background **daemon** supervising them. This is Claude Code's local anchor for Anthropic's server-hosted background-agent product.

**Agents Fleet / Agent View** — 🟢 default on (`isAgentsFleetEnabled` = `!Sjt()`). Disable via env `CLAUDE_CODE_DISABLE_AGENT_VIEW` or setting `disableAgentView`. Parent of everything below.

**Coordinator ↔ worker mode** — 🟠 env `CLAUDE_CODE_COORDINATOR_MODE`; capability `allow_cobalt_plinth`; telemetry `tengu_coordinator_mode_switched`. `coordinator` is a runtime MODE (not an agentType). Coordinator prompt: *"Every message you send is to the user."*, *"Do not use one worker to check on another. Workers will notify you when they are done."*, *"Do not set the model parameter. Workers need the default model…"*

**New subagent types:**
| agentType | purpose | gating |
|---|---|---|
| `worker` | autonomous fleet worker (`maxTurns:200, permissionMode:"bubble"`) | coordinator mode |
| `fork` | context-inheriting variant, `subagent_type:"fork"` | `tengu_fork_subagent_enabled` / `tengu_copper_fox` |
| `teammate` | in-process named teammate spawn | fleet |
| `workflow-subagent` | workflow-script orchestration | internal |

**Launch Composer + Composer Sidebar** — 🔴 DARK. `isLaunchComposerEnabled`, `shouldShowLaunchComposer`, `isComposerSidebarEnabled` all hardcoded `return !1`. A new prompt-authoring UI with a sidebar; ships in the Fleet module. No override exists yet.

**Past Sessions in Fleet** — 🟠 env `CLAUDE_CODE_FLEET_PAST_SESSIONS=true` OR `tengu_fleet_past_sessions`. Browse/resume past sessions from the Fleet view.

**Agent Swarms / Teams** — 🟠 env `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` AND `tengu_amber_flint` (default true). Multiple cooperating agents; injected into subagent env as `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`.

**Observer agents** — 🟡 `tengu_observer_agents_enabled` (default on). An agent that passively watches another's stream (`tool_call`/`tool_result`/`assistant_text`/`turn_ended`); no observer-of-observer chaining. Env `CLAUDE_CODE_EXPERIMENTAL_OBSERVER_AGENTS`.

**Fleet tools** (mid-rollout — already appear as deferred tools): `SendMessage` (inter-agent messaging), `TaskStop` (stop background task / teammate `name@team`), `Monitor` (background WebSocket watcher, `ambient`/`persistent` modes), `EnterWorktree` / `ExitWorktree` (isolated git-worktree sessions, hooks `WorktreeCreate`/`WorktreeRemove`).

## 2. Daemon — persistent background supervisor

`com.anthropic.claude-daemon`, invoked as `claude daemon <cmd>`. Launchd (macOS) / systemd (Linux) / WinSW (Windows) service. Lock file `daemon.lock`, events channel `com.anthropic.claude_code.events`.

- **Subcommands:** `run`, `status --json`, `hub` (interactive TTY dashboard), `scheduled`, `remote-control`, plus `logs / attach / stop / kill / respawn / rm`, `--bg/--background`.
- **What it does:** runs queued agent workers (`runDaemonWorker`, spare-process pool `spawnSpare`/`claimSpare`, task queue `maxQueued`/`runTimeoutMinutes`), the remote-control bridge, and scheduled routines.
- **Gates:** `isDaemonCliEnabled` (= agents-fleet, 🟡 on) · `isDaemonWorkerRegistryEnabled` 🔴 DARK · `isDaemonServiceInstallEnabled` = `tengu_amber_anchor` 🟠 · `isDaemonServiceRecalled` = `tengu_copper_lantern` 🟠 (kill-switch/recall) · cold-start policy `tengu_quiet_harbor`. The presence of a "recalled" kill-switch implies staged rollout is imminent.
- Opt-out: `CLAUDE_CODE_DISABLE_AGENT_VIEW` / `disableAgentView`; the noun flips "background service" → "daemon" once install is enabled.

## 5. Cloud / remote surfaces (server-gated)

All behind `teleport-org` auth + org policy (`allow_remote_sessions`, `allow_routines`) + betas.

- **Remote backend** — 🟠 `tengu_remote_backend`. `claude --cloud "task"` + attach-to-existing-cloud-session. Endpoints `/v1/code/sessions`, `/v1/code/github/import-token`.
- **Routines** — 🟠 server-side scheduled/recurring cloud agents. `/v1/code/triggers` + `/code/routines/` (cron + one-shot; `cron_expression`, `next_run_at`, `run_once_at`). Beta `ccr-triggers-2026-01-30`. *"Routines are disabled by your organization's policy."*
- **CCR bridge / remote-control** — 🟠 `tengu_ccr_bridge`. Pairs CLI to a desktop/phone controller over `ANTHROPIC_UNIX_SOCKET`; mirrors app state, auto-uploads sessions. `/v1/code/agent-proxy` (BYOC governed egress, writes `/run/ccr/session_token`, manages git config blocks). Beta `ccr-byoc-2025-07-29`. `isPersistentRemoteSessionEnabled` = 🔴 DARK.
- **Ultrareview** — 🟠 `/v1/ultrareview/preflight`. Deep multi-agent code review that "runs in Claude Code on the web"; `/ultrareview` + `/ultraplan` slash commands. Env fixture `CLAUDE_CODE_ULTRAREVIEW_PREFLIGHT_FIXTURE`.
- **Managed Agents** — 🟡 beta `managed-agents-2026-04-01` (125 hits, dominant). `client.beta.{agents,environments,sessions,vaults,memory_stores,deployments}`; `/v1/{agents,sessions,environments,deployments,files}`.
- **Teleport / desktop handoff** — `/teleport` (`allow_remote_sessions`), `/desktop` (`allow_desktop_handoff`, needs Claude Desktop app).
