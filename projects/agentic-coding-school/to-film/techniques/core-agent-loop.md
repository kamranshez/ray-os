# The Core Agent Loop (Observe → Think → Act)

Foundational loop ALL AI agents run: Observe (read context, files, tool results) → Think (reason about next step) → Act (call tools, edit files, run commands). Repeats until "definition of done." Context grows each iteration.

First principles of AI agents. Explains why context management matters, why planning saves time, why verification loops work. Show the thinking panel as visibility into the Think step. All tools (Claude Code, Codex, Gemini) run this same loop.
