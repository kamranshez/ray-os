## The Skill You Already Have (Blog Post to Skill)

You don't always build from scratch. Turn existing documents into skills.

### Core Concept

Take an article, a blog post, a documentation page, a company playbook you already reference regularly — and turn it into a skill. Encode it once, use it forever.

From the Zack Shapiro legal example: the difference between "review this contract" (generic) and a skill that knows your analytical framework, preferred format, severity ratings, and counter-language for each issue type.

### What to Show

**For this class's audience** (non-developers), re-record with a business example rather than cross-linking the existing Blog Post to Skill video (which uses React useEffect):

1. Take a real business document — proposal template, review checklist, client brief format, sales playbook
2. Feed it to Skill Creator: "Turn this into a Claude skill so I can apply this process to any new [proposal/contract/brief]"
3. Skill Creator interviews you about edge cases, then builds the skill
4. Test: run the skill on a sample document
5. Compare: output WITH the skill vs generic Claude on the same document

### The Brand DNA Video Pattern

"I told Claude I want to build a skill. I have a transcript atomizer prompt I use regularly. I want to turn it into a skill so anytime I give Claude a raw messy transcript, I can just say 'atomize this' and it runs without me having to paste, explain context, or anything." (Elliot)

Same principle — take something you do repeatedly, wrap it in a skill.

### The Playbook Angle

Zack Shapiro: "A template library is not a competitive advantage. Every competent firm in your practice area has roughly the same templates. The thing that differentiates a great lawyer from a mediocre one was never the template. It was what the lawyer did with the template."

Your playbook + a skill = your judgment encoded and repeatable.
