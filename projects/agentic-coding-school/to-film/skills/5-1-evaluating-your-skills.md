## Evaluating Your Skills

The key differentiator from all competitors. Stop guessing if your skills work.

### The Problem

"Up until now it was completely vibes based whether it was giving us high quality output or not. You had no way to actually measure whether your changes made things better or worse." (7 Levels)

### What to Show

Take the research skill from Ch 2 and run Skill Creator's eval feature.

**Step 1 — Define criteria** (3-5 assertions):
- Does the output include a TLDR?
- Does it cite sources?
- Does it assess pros/cons?
- Does it give a bottom-line verdict?

"I'd highly recommend when you run these evals doing three to five criteria at a time so you're not giving it too much to think about." (7 Levels)

**Step 2 — Run the eval**:
"Run a new test using the skill creator evals, optimize for making sure my content follows [specific criteria]." (7 Levels)

It spawns 10 agents — 5 with the skill, 5 without. Runs in parallel, grades against criteria.

**Step 3 — Read the benchmark dashboard**:
- Assertion pass rate (e.g., 93%)
- Time taken with vs without skill
- Token usage with vs without
- Per-assertion breakdown: which passed, which failed

"With the skill: 93% pass rate, 184 seconds, X tokens. Without: 93% pass rate but significantly lower time and tokens." (7 Levels)

**Step 4 — Act on results**:
- If a criterion fails, add it to the skill.md or a reference file
- Submit specific feedback: "we want to make sure it always checks for internal links — can we add anything to the skill.md?"
- It retests with the updated skill automatically

### Key Insight

"You can read the full output from each variation, see exactly where it passed and failed, and give feedback directly into the report, which then feeds back into improving the skill." (7 Levels)
