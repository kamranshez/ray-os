## The Interrogate Skill (Your First Build)

The simplest, highest-ROI skill anyone can build. Your first hands-on build.

### Why This Is First

It's pure text. No scripts, no references, no assets. Just a skill.md with ~30 lines. And it makes EVERYTHING better — every other skill you build will produce better output if the interrogate skill runs first.

It solves the #1 non-coder problem: giving Claude bad/incomplete input and getting bad output.

### Core Concept

A meta-skill that forces Claude to interview you exhaustively before doing any work. "Walk down each branch of the decision tree."

From Lenny's video: "This skill nudges the AI to get as much information as possible out of you based on whatever you're working on so you have the highest chance of success. The sentence about walking down each branch of the decision tree is really impactful."

### What to Show

1. **Write the skill.md by hand** — perfect for understanding the format:
   - Name, description, trigger keywords
   - Instructions: "Before executing any task, ask at least 5 clarifying questions. Explore edge cases. Walk down each branch of the decision tree. Only proceed when you have enough context."
   
2. **Test without the skill**: Ask Claude to "help me plan a marketing campaign" → it jumps straight to generic output

3. **Test WITH the skill**: Same prompt → Claude interviews you first. "What's the budget? Who's the audience? What channels? What's worked before? What's the timeline?"

4. **Compare outputs**: Shallow generic plan vs deeply contextualized plan from the same starting prompt

### Key Line

"That's really where the hard work is — giving it the information it needs so that going forward it has everything to be the best helper it can possibly be." (Lenny)

Brock's version shows this too — his "difficult conversation prep" skill asks follow-up questions: "Is this work or professional? What's the core issue? Main concern? Who are you speaking with?" All preconfigured in the skill.

### The 20-Minute Investment

Lenny's example: "That interrogation took about 20 minutes to fill all of that out." But that 20 minutes of input saves hours of bad output and re-prompting.
