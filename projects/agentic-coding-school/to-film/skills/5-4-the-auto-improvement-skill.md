## The Auto-Improvement Skill (Your System Tells You What to Build Next)

Different from 5.3 (where a skill improves ITSELF). This is about your SYSTEM suggesting what to build next.

### Core Concept

A meta-skill that looks back on everything you've done across all your skills and suggests NEW skills to build.

From Lenny's video: "This is the auto improvement skill. It looks back on everything that we've done in a specific chat or project and says, 'Hey, here are some things we can do better. Here are some other skills maybe that we can build that will help speed things up and gain efficiency.' This is one way to sort of self-improve your processes going forward."

### What to Show

1. Build an "auto-improve" skill that reviews recent sessions and identifies:
   - Repetitive tasks you're still doing manually → should be a skill
   - Steps in existing workflows that could be broken into sub-skills
   - Gaps in your system (e.g., "you have content creation but no content distribution")

2. Run it on the system built across the class

3. "It gave us some great ideas for other skills like a materials estimator, project tracker, DIY build guide — some really cool stuff." (Lenny)

4. Pick one suggestion and build it live using Skill Creator

### Why This Matters

The class teaches you to build 15-20 skills. But your system should grow to 30-50+ over time. This skill is how that happens without auditing your own workflow.

It's the growth loop: use skills → auto-improve identifies gaps → build new skills → use them → repeat.

### The Project Tracker Example

From Lenny: "I've gone ahead and built that project tracker skill. I think that could be very valuable." — He took the auto-improvement suggestion and immediately acted on it.
