## Chaining and Stacking Skills

Two ways skills work together. Most people only know about one.

### Chaining (Sequential)

Skill A finishes → skill B starts → skill C finishes. A pipeline.

From solopreneur video: "First the ideation skill kicks in — researches competitors, finds what's trending, generates nine video ideas. Then the script writing skill takes over — writes full scripts in my exact voice. Then it organizes everything into a content calendar with upload dates."

"All that is done with just one command: 'plan and script my next batch of videos.'" (Solopreneur)

### Stacking (Parallel)

Multiple skills active simultaneously on the same task. They layer like filters.

From Elliot: "I can have this dashboard skill, writing-in-Elliot's-voice skill, apply-my-branding skill, and output-it-in-an-AI-recipe skill. It can load multiple and work together, link them together."

### What to Show

**Chaining example**:
"Plan and script my next batch of videos" → ideation → scripting → calendar → humanizer gate. Show the sequential handoff.

**Stacking example**:
"Create a client proposal" → brand applicator + voice skill + proposal template all active at once. Show `/context` to see multiple skills loaded simultaneously.

**Combined**:
"Process this week's finances" → receipt scanner → expense categorizer (chain) with brand applicator stacked on top for consistent visual output.

### Auto-Routing

"Claude Co-work is smart enough to automatically figure out which skills to use based on what you're asking. You don't have to manually tell it use skill A, then skill B, then skill C. You just describe the task." (Solopreneur video)

"Once your skills are set up, you're literally just talking to your AI employees like you would talk to a real person. 'Hey, plan my next videos. Hey, how many leads did I get? Hey, how are the ad campaigns running?'" (Solopreneur video)

### Architecture

Chaining = departments (sequential pipeline)
Stacking = layers (parallel enrichment)
Skills calling sub-skills = depth without bloating any single skill
