### Detailed Competitor Breakdown — What Each Video Covers & Key Demos

**Video 1 — AI Edge** (jw0pMr54Ztc) — "Ultimate Beginner's Guide"
- Personal angle: "switched to Claude for 90% of my AI usage"
- **Pricing breakdown**: Free → Pro ($20) → Max ($100) → Max ($200). Key insight: "biggest jump is between free and Pro." CoWork uses significantly more credits than chat.
- **Platform options**: web, desktop (preferred for Mac), mobile (has voice transcription that desktop lacks)
- **Prompting structure** (vetted by Anthropic people): (1) set the stage (who you are), (2) define the task, (3) specify audience, (4) set rules/constraints, (5) ask it to ask you questions. Offers free prompt pack.
- **Document analysis**: uploads his own video notes, asks Claude to review and suggest improvements. Notes "Opus is one of the best models" at document analysis.
- **Research mode**: demos "research all layoffs in tech this past week" — takes 5-20 minutes, returns thorough report. Uses alongside Perplexity and GPT Pro.
- **Connectors**: Gmail, Calendar, Drive. Calls this "underrated." Pro tip: hook up Gmail to feed data into coding sessions.
- **Projects deep dive**: creates "Executive Assistant" project. Key structure:
  - Upload a one-pager about yourself (some of his are 3-6 pages)
  - Create separate chats for different purposes: "brainstorming," "day-to-day ops"
  - Memory stacks over time across chats within a project
  - Mentions Claude's memory window recently expanded
- **Skills**: creates skills by telling Claude "I'd like to create a skill for XYZ, help me do this." Think of skills like /slash commands.
- **Artifacts**: financial dashboard demo — net worth over time, monthly income, savings rate, top holdings. "Built this in 10 seconds." Key distinction: artifacts ≠ vibe coding. Artifacts = basic stuff in chat. Code tab = real development.
- **CoWork brief mention**: "autonomously works on a folder on your computer while you do other stuff."
- **Models**: Opus for advanced tasks, Sonnet for chatting/cost preservation. Haiku "not preferred, rarely used."

**Video 2 — AI Master** (m54t8xx13Uk) — "Ultimate Claude 4.5 Guide"
- Most technical/benchmark-heavy of the 4
- **Model breakdown with benchmarks**:
  - Sonnet: SWE-bench 77.2%, $3/$15 per M tokens. "Daily driver."
  - Opus: SWE-bench 80.9% (first to break 80%), $5/$25. Has "effort parameter" (high/medium/low). "Safety net for final reviews."
  - Haiku: SWE-bench 73.3%, $1/$5. "Surprise star — 90% of Sonnet at 1/3 cost." Near-instant. Loses track in long sessions.
- **Extended thinking deep dive**: shows thinking block, explains interleaved thinking between tool calls. "Transparency — you see the work, trust the output, catch mistakes." Note: impacts prompt caching efficiency.
- **Claude vs Gemini 3 Pro comparison**: Gemini wins on multimodal (video, images). Claude wins on code reliability and agent workflows. "Use Gemini for frontend visuals, Claude for backend logic and mission-critical work."
- **Context windows**: all models 200K tokens. Sonnet has 1M beta. 200K ≈ 600-page book.
- **Artifacts workspace**: two tabs — Inspiration (templates) and Your Artifacts. New artifact button → pick category (apps, documents, games, productivity, creative, quiz, scratch) → Claude asks clarifying questions → side panel renders. Real-time iteration. "Claude doesn't just show code — it executes it."
- **Projects**: "persistent workspaces — like folders where files and context live." Every chat in a project knows uploaded files. Connects to Google Drive. Demo: job hunt project with resume, cover letters, portfolio.
- **Practical applications**: document analysis (200-page papers, contract review), content writing (5000-word articles with artifact editing), data analysis (sales data → charts in artifacts), agent workflows (Sonnet orchestrates, Haiku sub-agents execute in parallel), customer support (Haiku at scale).

**Video 3 — AI Foundations** (rRrBbyv3ChM) — "FULL Claude Tutorial"
- Most production-quality tutorial of the 4, very structured
- **Pricing**: free plan "genuinely good" but recommends Pro for commitment. "Get some skin in the game." Currently at claude.com/pricing.
- **Prompting techniques**: context → task → format → iterate. "Treat Claude like a colleague — give context, ask for structure, then refine." Key technique: upload reference material and ask Claude to match the style.
- **Research mode**: deep research on course market — market size, growth trends, pricing ranges, popular platforms, demand vs competition. 5-20 minute processing.
- **Artifacts extensive demo**:
  - Financial dashboard with multiple chart types
  - Pomodoro timer (functional app)
  - Data visualization from uploaded spreadsheets with interactive filtering
  - Document formatting (proposals, reports)
  - Diagrams and flowcharts
  - Key: "iterate through conversation — build then refine"
- **Projects + AI OS concept**: creates 4 projects — Executive Assistant, Content, Business, Learning. Each has: instructions (who you are, how Claude should work), files (reference docs), memory (builds over time), dedicated chats. This is the "AI operating system" framing.
- **Connectors**: Gmail, Calendar, Drive. Demo: email briefing + meeting prep + weekly planning, all pulling from real data.
- **Extended thinking**: before/after comparison on business strategy prompt. Without = generic advice. With = specific, numbers-based, considers capacity constraints.
- **Files & documents**: PDF analysis (200-page report → 5-bullet summary), spreadsheet analysis (sales data → trends + dashboard artifact), image analysis (screenshots, handwritten notes, charts), multi-file processing (5 invoices → combined summary).
- **Chained workflows**: "stop thinking in tasks, start thinking in systems" — research → extract → compare → draft in one instruction.

### What EVERY competitor covers (saturated)

- Pricing breakdown (free → Pro → Max)
- Basic prompting advice ("be specific," "give context")
- Artifacts demos (dashboards, apps)
- Projects (creating, uploading files)
- Connectors (Gmail, Calendar, Drive)
- Model overview (Opus smart, Sonnet balanced, Haiku fast)

### What's MISSING or surface-level across all 4

1. **Prompting depth** — AI Edge has the best structure but it's still just one example. Nobody does progressive prompting exercises.
2. **Extended thinking practical applications** — AI Master explains it technically, AI Foundations shows one comparison. Nobody shows multiple real use cases.
3. **Artifact iteration workflow** — everyone builds one artifact. Nobody shows the iterative refinement process (build → critique → revise × 5 rounds).
4. **Project architecture** — AI Edge and AI Foundations both set up projects but don't show how to organize for scale or maintain over weeks.
5. **Memory management** — mentioned by all, managed by none. Nobody shows reviewing, editing, or cleaning up memory.
6. **File analysis patterns** — everyone uploads one file. Nobody shows batch processing or multi-file comparison patterns.
7. **Research + artifact pipeline** — research a topic, then visualize findings. Nobody chains these features.
8. **Daily workflow integration** — AI Foundations touches this with the "AI OS" concept but doesn't show a real daily routine.
9. **Connector workflows beyond basics** — everyone connects Gmail, nobody shows a complete email-to-action pipeline.
10. **Model switching strategy** — everyone says "use Sonnet for daily, Opus for complex" but nobody shows when to switch mid-conversation.

## Cross-Course Synergies (Claude Chat ↔ Claude CoWork)

These two courses share concepts but approach them differently:

| Concept | Chat Course Coverage | CoWork Course Coverage |
|---------|---------------------|----------------------|
| Projects | Creating projects in chat interface | Creating projects in co-work with folder access |
| Memory | Memory across chat conversations | Memory + CLAUDE.md files + global instructions |
| Connectors | Gmail/Calendar/Drive in chat | Same connectors + skills + scheduled automation |
| Skills | Brief mention (chat skills/artifacts) | Deep dive: creation, debugging, chaining, scheduling |
| Models | When to use Opus/Sonnet/Haiku | Brief: use Sonnet for scheduled tasks, Opus for complex |
| Prompting | 5-part structure, techniques | Task delegation prompts, skill instruction writing |
| Artifacts | Core feature: dashboards, apps, docs | Not available in co-work (outputs are files instead) |
| Research | Web search + deep research mode | Browser automation via Chrome extension |

**Recommendation**: Film Claude Chat first (standalone value), then CoWork (builds on concepts). Some viewers will take both; the overlap is minimal because the interfaces and use cases are different.
