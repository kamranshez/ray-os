## Video 1 — What is Claude + Getting Set Up

**Goal**: Viewer goes from zero to signed up and ready to use Claude — understands what it is, how to access it, and which plan to pick.

---

### HOOK (0:00–0:30)

> "If you've been using ChatGPT for everything, you're leaving a lot on the table. Claude is the AI tool that's been quietly winning over developers, writers, and business owners — and in this course I'm going to show you everything it can do. This first video: what Claude actually is, how to sign up, which plan to pick, and a quick tour of the interface so you're not lost when we dive deeper."

---

### SECTION 1: What is Claude? (0:30–2:30)

**On screen**: Claude.ai homepage.

> "Claude is an AI assistant built by Anthropic. You can think of it like ChatGPT, but with a different personality and different strengths. You chat with it, ask it questions, give it tasks — and it responds with text, code, analysis, even interactive apps."

**What makes Claude different from ChatGPT**:
- Better at creative writing — scripts, essays, long-form content feel more human
- Better at following complex instructions — it sticks to your rules more reliably
- Artifacts — it can build interactive apps, dashboards, and documents right in the chat
- Projects — built-in workspace system with persistent memory
- Three products in one app: Chat, Code, and CoWork

> "Over this course we're going to cover all of it. But today we're just getting you set up."

**Reference from competitors**: AI Edge says "the way you have to think about Claude is less like a chatbot and more like a co-worker that can actually assist you to do tasks." AI Foundations frames it as "everything you need is already built in — you don't need to connect 30 different tools."

### SECTION 3: Which Plan Should You Pick? (4:00–7:00)

**On screen**: Claude pricing page (claude.ai/pricing).

> "Claude has four tiers. Let me break them down so you pick the right one."

**Free Plan**
- Access to Claude Sonnet (their mid-tier model)
- Web search, file uploads, artifacts
- Daily usage caps — you'll hit limits with heavy use
- > "The free plan is genuinely good for trying things out. But if you use AI daily, you'll hit the wall fast."

**Pro Plan — $20/month**
- 5x the usage of free
- Access to ALL models including Opus (the smartest one)
- Projects for organizing work
- Deep research mode
- Google Workspace integration (Gmail, Calendar, Drive)
- Extended thinking (smarter, more thorough answers)
- > "This is where I'd start if you're serious about AI. The jump from free to Pro is the biggest upgrade."

**Max Plan — $100/month**
- 5x Pro's usage limits
- Bigger context window
- Built for power users who live in Claude all day
- > "If you're constantly hitting rate limits on Pro, upgrade to Max. Otherwise Pro is plenty."

**Max $200/month**
- 20x Pro's usage limits
- For heavy coders, researchers, and teams
- > "You'd have to be going absolutely crazy to need this tier."

**Recommendation**:
> "Start with Pro. $20/month. If you hit limits regularly after a couple weeks, upgrade to Max. Don't overthink it."

**Reference from competitors**: AI Edge gives the same advice: "the biggest jump in advancement is between the free subscription and the pro subscription." AI Foundations: "I just remember when I went from free to the next plan up, this is when everything started to change." AI Master breaks down benchmarks per model but for beginners, the plan choice matters more.

### SECTION 4: Where to Use Claude (7:00–8:30)

**On screen**: Show each platform briefly.

> "You can use Claude in four places."

1. **Web app** — claude.ai in your browser
   - Works on any device
   - Full feature set
   
2. **Desktop app** — Mac and Windows
   - Download from claude.ai/download
   - Gives you access to CoWork and Code tabs
   - > "I recommend the desktop app for daily use. It feels snappier and unlocks CoWork features."

3. **Mobile app** — iOS and Android
   - Great for on-the-go questions
   - Voice input (you can talk to Claude)
   - Dispatch (trigger desktop tasks from your phone)

4. **API** — for developers building with Claude
   - Not relevant for this course

> "For this course, I'll be using the desktop app. But everything I show works on the web app too."

### SECTION 5: Quick Tour of the Interface (8:30–12:00)

**On screen**: Claude desktop app, fresh login.

> "Let me give you a quick tour so you know where everything is."

**The chat input** (center bottom)
- This is where you type your messages
- You can also drag in files, images, PDFs
- > "Just start typing and hit Enter. That's 90% of how you'll use Claude."

**The model selector** (bottom or top)
- Show switching between Opus, Sonnet, Haiku
- > "We'll cover which model to use in a later video. For now, Sonnet is fine for everything."

**The sidebar** (left)
- All your conversations listed
- Star/pin important ones
- Projects section at the bottom
- > "Think of this like your email inbox. Each conversation is a separate thread."

**The "+" button / new chat**
- Start a fresh conversation
- Show the options that appear: web search, research, connectors, etc.
- > "Every time you start a new chat, you get a clean slate. Claude doesn't remember previous chats unless you're in a Project — we'll cover that later."

**Artifacts panel** (right side)
- This is where interactive outputs appear — dashboards, apps, documents
- > "When Claude creates something visual, it appears here. This is one of Claude's killer features."

**The three tabs** (top — desktop app only)
- **Chat** — conversational AI (what we're covering in this course)
- **Code** — for developers (terminal-based coding agent)
- **CoWork** — task delegation with file access (separate course)
- > "This course focuses on Chat. We have separate courses for Code and CoWork."
