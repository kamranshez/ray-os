## Video 9 — Files & Documents

**Goal**: Viewer learns to upload and analyze PDFs, spreadsheets, images, and documents — turning Claude into a document processing powerhouse.

---

### HOOK (0:00–0:30)

> "Claude can read PDFs, analyze spreadsheets, interpret images, and process documents — all by dragging a file into the chat. In this video I'm going to show you how to use this for real work: extracting data from invoices, summarizing reports, analyzing images, and more."

---

### SECTION 1: How to Upload Files (0:30–2:00)

**On screen**: Claude chat with file upload.

> "Getting files into Claude is dead simple."

**Three ways**:
1. **Drag and drop** — drag a file directly into the chat input
2. **Click the paperclip/attachment icon** — browse your files
3. **Paste from clipboard** — screenshots, copied text

**Supported file types**:
- PDFs
- Word documents (.docx)
- Spreadsheets (.csv, .xlsx)
- Images (.png, .jpg, .gif)
- Code files
- Text files
- PowerPoint (.pptx)

> "Pretty much any common file format works. You can upload multiple files at once too."

### SECTION 2: Demo 1 — PDF Analysis (2:00–5:00)

**On screen**: Upload a PDF and analyze it.

> "Let's start with the most common use case: PDFs."

**Upload a research paper or business report** (something dense and multi-page).

Type:
```
I just uploaded a 30-page industry report. Can you:
1. Give me a 5-bullet executive summary
2. List the key statistics and data points
3. Identify the 3 most important findings
4. Flag anything that seems surprising or counterintuitive
```

- Show Claude processing the PDF
- Show the structured summary

> "30 pages down to 5 bullets, with the key stats pulled out. That would have taken me 45 minutes to read and summarize."

**Follow-up**:
```
On page 12, there's a claim about market growth. 
What evidence do they provide and how strong is it?
```
- Show Claude referencing a specific section
- > "You can ask follow-up questions about specific parts. Claude remembers the entire document in context."

**Reference from competitors**: AI Edge notes "Claude's ability to read PDFs, images, documents is really strong. I find Opus is actually one of the best models at this."

### SECTION 3: Demo 2 — Spreadsheet Analysis (5:00–8:00)

**On screen**: Upload a CSV or Excel file.

> "Spreadsheets are where Claude gets really practical."

**Upload sales data** (or any business spreadsheet).

Type:
```
Analyze this sales data. I want:
1. Total revenue by month for the last 6 months
2. Which product category is growing fastest?
3. Who are my top 5 customers by total spend?
4. Any trends or anomalies I should know about?
5. Create a summary table with the key metrics.
```

- Show Claude crunching the numbers
- Show the analysis with actual calculations
- > "It read every row, did the math, and found the trends. No formulas needed."

**Follow-up with artifact**:
```
Now create an interactive dashboard visualizing this data.
Include a monthly revenue chart and a category breakdown pie chart.
```
- Show the artifact appearing with the visualized data
- > "Uploaded a spreadsheet, got analysis AND a visual dashboard. Try doing that with ChatGPT."

### SECTION 5: Demo 4 — Multi-File Analysis (10:00–11:30)

**Upload 3-5 related documents** (e.g., multiple invoices, competing proposals, quarterly reports).

```
Create a spreadsheet summary with: vendor name, date, category, amount, tax, total.
Then tell me my total spending by category.
```

- Show Claude processing all 5 files
- Show the combined summary

> "Five separate PDFs processed into one clean summary with totals. This is the kind of task that takes 30 minutes manually."

---

### SECTION 6: Tips (11:30–12:30)

1. **Ask specific questions** — "Summarize this" is okay; "Find the revenue numbers and compare Q1 vs Q2" is better
2. **Use in projects** — upload reference docs to a project so they're always available
3. **Combine with artifacts** — analyze data, then visualize it in one conversation
4. **Multiple files at once** — Claude handles batch processing well
5. **Follow up** — ask about specific sections, challenge findings, request different formats
