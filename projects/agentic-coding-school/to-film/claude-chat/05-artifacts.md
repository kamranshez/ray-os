## Video 5 — Artifacts

**Goal**: Viewer understands artifacts, builds interactive dashboards, apps, and documents inside Claude — and knows how to export them.

---

### HOOK (0:00–0:30)

> "This is the feature that makes Claude different from every other AI chatbot. Artifacts. Instead of just giving you text, Claude can build interactive apps, dashboards, games, and documents — right inside the chat. You can click through them, interact with them, and export them. Let me show you what's possible."

---

### SECTION 1: What Are Artifacts? (0:30–2:30)

**On screen**: Claude chat with an artifact open in the side panel.

> "An artifact is an interactive output that Claude creates alongside its text response. Instead of giving you a wall of code or a description of what something could look like, it actually builds it and shows it to you."

**Types of artifacts**:
- Interactive web apps (dashboards, calculators, tools)
- Documents (formatted reports, letters, proposals)
- Diagrams and charts (data visualizations, flowcharts)
- Games and creative projects
- Code that runs in real-time

> "The artifact appears in a panel on the right side of the chat. You can interact with it, resize it, and keep iterating on it through conversation."

**Reference from competitors**: AI Edge calls artifacts "probably the most impressive thing about Claude" and "visual representations of data that pop up within the app and you can export them to become websites." Riley Brown traces artifacts back to May 2024 as the feature that started the "vibe coding era." AI Master explains the artifacts workspace with inspiration gallery and the new artifact button.

### SECTION 2: Demo 1 — Financial Dashboard (2:30–5:30)

**On screen**: Build a dashboard live.

Type:
```
Create an interactive financial dashboard for a freelancer.
Include: monthly income vs expenses bar chart, savings rate over time, 
a pie chart of expense categories, and a net worth tracker.
Use sample data for a freelancer earning $8K/month.
Make it dark themed and professional.
```

- Show Claude generating the artifact
- Show the dashboard appearing in the side panel
- Click through the interactive elements
- > "Look at that. A full interactive dashboard built in about 10 seconds. Charts you can hover over, data that's organized, dark theme. I didn't write a single line of code."

**Iterate on it**:
```
Add a toggle to switch between monthly and quarterly views.
Also add a section that shows top 3 expense categories as a ranked list.
```
- Show the artifact updating
- > "I'm just talking to Claude and the dashboard evolves. This is what makes artifacts so powerful — you iterate through conversation."

**Reference from competitors**: AI Edge builds a similar financial dashboard live — "it's showing my net worth over time, monthly income, savings rate, top holdings — and I built this in a second."

### SECTION 6: Exporting Artifacts (11:30–12:30)

**On screen**: Export options.

> "Once you've built something you like, you can get it out of Claude."

**Options**:
- **Copy code** — grab the HTML/JavaScript to host it yourself
- **Download** — save as a file
- **Open in new tab** — run it in a full browser window
- **Share** — send a link to someone

> "I've built landing pages, client dashboards, and internal tools as artifacts and then deployed them to real websites. The code Claude generates is clean enough to use directly."

---

### SECTION 7: Tips for Better Artifacts (12:30–13:30)

1. **Be specific about design** — "dark theme, professional, minimal" vs just "make a dashboard"
2. **Iterate in conversation** — don't try to get it perfect in one prompt. Build, then refine.
3. **Upload real data** — artifacts with your actual data are 10x more useful than sample data
4. **Ask for interactivity** — "make it clickable," "add filters," "add tooltips on hover"
5. **Combine with research** — research a topic first, then create an artifact to visualize the findings
