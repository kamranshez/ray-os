Stub — how to write the objective the /goal runtime is going to execute against. Avi Chawla's 9-section template, Weinbach's "anchor on a theoretical max" tip, Ray's WatchLLM goal as the worked example.

## Key beats

- The 9-section template walk-through.
- Theoretical max framing: "the best version of this would be X." Anchor the goal to the upper bound, not to current performance.
- WatchLLM goal as the worked example. Show the actual goal file on screen.
- Failure modes: success criteria that defer to the model, no kill criteria, no tradeoff order.
- Connection to [[mission-command]]: a /goal is the tactical version of an intent doc. Same anatomy, narrower scope.
