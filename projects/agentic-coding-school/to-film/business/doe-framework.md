# DOE Framework (Directive Orchestration Execution)

Three-layer architecture for business workflows: Directive (SOPs/checklists as markdown), Orchestration (AI agent reads directives, makes decisions), Execution (scripts, API calls, browser actions). Predecessor to skills — same concept, formal name.

Business-person mental model: think in checklists not code. Build a sales pipeline end-to-end. CRM integration (ClickUp, HubSpot via MCP).
