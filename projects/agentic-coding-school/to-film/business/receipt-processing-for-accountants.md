## Receipt & Invoice Processing

Directly relevant to John Kim's accounting clients.

Demo the headless mode receipt processing workflow:
1. Drop receipts/invoices (photos, PDFs) into a folder
2. Run a batch script that processes each one
3. Claude extracts: vendor, date, amount, category, tax info
4. Outputs structured CSV or JSON for import into accounting software

**Key demo:** Process 20 receipts in one go, outputting a clean spreadsheet.
