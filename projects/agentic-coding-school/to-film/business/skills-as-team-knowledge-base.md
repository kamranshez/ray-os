## Skills as a Team Knowledge Base

Turn years of accumulated expertise into an instruction file that any team member can use from day one.

> "The plugin is transferable. If I had 50 associates, I could install it on every machine. Every associate would immediately produce contract reviews using my analytical framework, draft communications in my voice, and apply tracked changes in my preferred format. Knowledge that takes years of mentorship to transmit is now an instruction file that works from the first draft."
> — [Zack Shapiro (@zackbshapiro)](https://x.com/zackbshapiro/status/2027389987444957625)

### What to Cover

1. **The mentorship bottleneck** — Senior expertise normally transfers through years of osmosis: shadowing, feedback loops, institutional memory. Skills compress that into a file.

2. **Building a team skill plugin** — Demo: create a multi-skill plugin for a small team that encodes:
   - Client communication voice and tone
   - Proposal review framework with severity ratings
   - Onboarding checklist with decision criteria
   - Quality standards and formatting preferences

3. **The quality floor** — Skills don't replace review, they raise the starting baseline.

   > "The output still requires attorney review, but the review starts from a much higher baseline."
   > — [Zack Shapiro (@zackbshapiro)](https://x.com/zackbshapiro/status/2027389987444957625)

4. **Distribution** — How to share skills across a team: Git repos, shared drives, or `managed-settings.json` for enterprises (connects to the planned enterprise config video).

5. **The staffing implication** —

   > "The work that traditionally justified an associate hire — first-pass document review, research memos, initial drafts, redline summaries, routine correspondence — is now handled by Claude under my supervision... Associates are not obsolete. But the bar for when hiring one makes economic sense has moved."
   > — [Zack Shapiro (@zackbshapiro)](https://x.com/zackbshapiro/status/2027389987444957625)

### Key Demo

Create a "client onboarding" skill, share it with a second Claude instance simulating a new team member, and show both producing consistent output from the same input — compared to what a blank Claude session produces without the skill.
