## New Class: Claude Code for Business

**Tagline:** Automate your business workflows without writing a single line of code.

**Target audience:** Business owners, marketers, accountants, consultants, solopreneurs — people who want Claude Code's power without needing to be developers. People like John Kim (marketing + accounting clients).

**Positioning:** The existing classes teach you to *build software* with Claude Code. This class teaches you to *run a business* with it.

### Why this class

1. Direct customer demand (John Kim + likely many others asking similar questions)
2. Massively underserved market — most Claude Code content assumes you're a developer
3. Claude Code's MCP servers, skills, headless mode, and browser automation make it genuinely powerful for non-coding workflows
4. Expands TAM of the course significantly

### Landing page angle

Separate landing page or section: "Not a developer? Start here."
- Emphasize zero-code workflows
- Show real business outcomes (time saved, content produced, research automated)
- Use cases front and center: marketing, research, content, operations

## Proposed Chapter Structure

### Chapter 1: Getting Started (No Code Required)
1. **Introduction** — What Claude Code can do for non-developers (set expectations)
2. **Installation & Setup** — Getting Claude Code running (macOS/Windows), subscription tiers
3. **Your First Conversation** — Basic prompting, reading files, organizing folders
4. **Thinking in Files** — How Claude Code thinks about your work as a file system (connecting to "company as a file system" concept)

### Chapter 2: Research & Intelligence
5. **Deep Research with Exa** — Setting up the Exa MCP server, running market research, competitive analysis
6. **Web Research Workflows** — Using web search/fetch to gather intel on competitors, trends, pricing
7. **Research Loops** — Building a skill that periodically researches a topic and updates a knowledge file (John's "loop that feeds the system" request)
8. **Summarizing Long Documents** — PDFs, reports, legal docs, financial statements

### Chapter 3: Content Production
9. **Writing with Claude Code** — Blog posts, newsletters, email sequences, using skills for voice/style
10. **Copywriting Workflows** — Landing pages, ad copy, A/B test variations
11. **Social Media Management** — Creating a content calendar, batch-generating posts, platform-specific formatting
12. **Content Repurposing** — Turn one piece of content into tweets, LinkedIn posts, email, blog posts

### Chapter 4: Marketing Automation
13. **Email Marketing Flows** — Drafting sequences, personalization, follow-ups
14. **SEO Research & Optimization** — Keyword research, content briefs, meta descriptions
15. **Competitor Analysis** — Automated monitoring of competitor content, pricing, positioning
16. **Lead Research & Outreach** — Using Exa to find prospects, draft personalized outreach

### Chapter 5: Operations & Admin
17. **Receipt & Invoice Processing** — Using headless mode to batch-process financial documents (connecting to existing headless mode video)
18. **Data Organization** — Structuring messy data, CSV processing, report generation
19. **Client Deliverable Templates** — Standardizing reports, proposals, presentations
20. **Meeting Notes & Action Items** — Processing transcripts, extracting next steps

### Chapter 6: Browser Automation
21. **Claude in Chrome for Business** — Navigating websites, filling forms, extracting data
22. **Social Media Posting** — Using browser automation to actually post content
23. **Price Monitoring & Market Watch** — Automated checking of competitor sites
24. **Data Entry Automation** — Filling CRMs, updating spreadsheets, form submissions

### Chapter 7: Building Your System
25. **Skills for Your Business** — Creating reusable skills for your specific workflows (brand voice, templates, processes)
26. **Headless Automation** — Running batch jobs on autopilot (receipts, content generation, research)
27. **The Daily Dashboard** — A morning briefing skill that pulls together your business intel
28. **Connecting It All** — MCP servers, skills, and headless mode working together as a system
