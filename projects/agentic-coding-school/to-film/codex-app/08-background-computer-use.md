## Background Computer Use

This video is about the difference between Codex using your cursor and Codex having its own cursor.

Foreground Computer Use feels like handing Codex your mouse. Background Computer Use feels like giving Codex its own workspace so you can keep using your machine while it operates another app.

## Big Picture

Background Computer Use is for GUI-only workflows where files, APIs, plugins, or MCP are not enough.

It should also be framed with judgment: avoid sensitive admin actions, financial actions, and anything where final confirmation requires human taste.

## Teaching Line

> Foreground Computer Use is like handing Codex your mouse. Background Computer Use is like giving Codex its own mouse.

## Visual Variations

### Variation 1: One Mouse vs Two Cursors

Big idea: compare foreground control with background control.

Core labels: your cursor, Codex cursor, keep working, separate task.

### Variation 2: GUI-Only Workflows

Big idea: show Codex operating a desktop app that has no clean API.

Core labels: desktop app, setup flow, export file, ask before destructive actions.

### Variation 3: Good Use / Bad Use

Big idea: show safe background tasks on one side and risky tasks on the other.

Core labels: testing, exporting, uploading, avoid finance, avoid final judgment.
