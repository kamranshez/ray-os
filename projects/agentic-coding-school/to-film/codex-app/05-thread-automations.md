## Thread Automations

This video is about the difference between a normal automation and a thread automation.

A normal automation starts from a prompt. A thread automation starts from a conversation that already understands the job: the project, the tools, the output style, the edge cases, and the corrections the user made along the way.

## Big Picture

Thread Automations turn a good Codex conversation into a recurring worker.

Instead of rebuilding context every time, Codex wakes the same thread back up on a schedule and continues from the accumulated understanding in that conversation.

## Teaching Line

> A normal automation starts from a prompt. A thread automation starts from a conversation that already understands the job.
