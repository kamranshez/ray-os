## Worktree Mode

This video is about using worktrees as the default professional workflow for parallel agents and experiments.

Worktree mode makes it safer to let multiple Codex threads work at the same time because each one gets its own isolated copy of the repo.

## Big Picture

Worktrees let you treat agents like separate junior developers, each working in their own isolated copy of the codebase.

The key mental model is not "more agents." It is "separate workspaces for separate attempts."

## Teaching Line

> Worktrees make parallel agents safer because their changes do not collide in the same folder.

## Visual Variations

### Variation 1: One Repo, Three Isolated Copies

Big idea: show a main repo branching into three worktrees, each with a different agent task.

Core labels: main repo, worktree A, worktree B, worktree C, isolated changes.

### Variation 2: Collision vs Isolation

Big idea: compare two agents editing the same folder with two agents working in separate worktrees.

Core labels: collision, isolated, inspect, keep, discard.

### Variation 3: Agent Workbench

Big idea: show worktrees as separate benches where agents can experiment without touching the main desk.

Core labels: experiment, review, merge, clean up.
