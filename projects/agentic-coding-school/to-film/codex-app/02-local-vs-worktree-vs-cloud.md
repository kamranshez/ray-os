## Local vs Worktree vs Cloud

This video is about the run-location selector.

Before students send prompts, they need to know where Codex is actually going to work. Local, Worktree, and Cloud are not just performance settings. They change the risk profile, isolation, and workflow.

## Big Picture

Local means Codex touches the selected project folder directly.

Worktree means Codex works in an isolated Git worktree.

Cloud means Codex runs remotely in the background.

## Teaching Line

> Before sending a prompt, you should know where Codex is going to touch files.

## Visual Variations

### Variation 1: Three Work Locations

Big idea: show one project splitting into three possible run locations.

Core labels: local folder, isolated worktree, cloud run, same prompt, different place.

### Variation 2: Risk Ladder

Big idea: show Local, Worktree, and Cloud as a ladder of directness and isolation.

Core labels: direct edits, safer experiment, background run.

### Variation 3: Choose The Right Mode

Big idea: show three task cards routed to the best mode.

Core labels: small bug fix, parallel experiment, long-running task.
