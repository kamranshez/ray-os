## SSH / Remote Devboxes

This optional video is about running Codex against projects that should not or cannot run directly on the laptop.

Remote devboxes matter for heavy repos, sensitive environments, special dependencies, and projects where the real development environment already lives on another machine.

## Big Picture

The mental model is simple: Codex is still the agent, but the working environment moves from the laptop to a remote devbox.

Record only if the feature is visible and stable enough in the current app.

## Teaching Line

> Remote devboxes are for projects that are too heavy, too specific, or too sensitive to run directly on your laptop.
