## Built-in Terminal & Multiple Terminal Tabs

This video is about Codex as a real development environment, not just a chat box that edits files.

The built-in terminal lets Codex live inside the same feedback loop a developer uses: run the app, run tests, read errors, fix problems, and verify the result. Multiple terminal tabs make that loop feel practical because one tab can hold the dev server while another runs tests or Git commands.

## Big Picture

Codex gets much more useful when the terminal becomes part of the conversation.

The core shift is from "Codex wrote code" to "Codex ran the system and learned from what happened."

## Teaching Line

> The terminal is what turns Codex from a file editor into a real development environment.
