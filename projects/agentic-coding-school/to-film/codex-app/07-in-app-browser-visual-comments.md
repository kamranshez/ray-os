## In-App Browser & Visual Comments

This video is about visual feedback on the thing you are building.

The in-app browser is different from generic Browser Use. It is for opening the local app, seeing the rendered UI, leaving comments on specific parts of the page, and asking Codex to fix the visual problems.

## Big Picture

The browser turns frontend work into a visual review loop.

Students should understand that screenshots, rendered pages, and visual comments give Codex context that code alone does not provide.

## Teaching Line

> The in-app browser is for visual feedback. Browser Use is for browsing and interacting with websites.

## Visual Variations

### Variation 1: Code To Screen To Comment

Big idea: show code becoming a rendered page, then visual comments becoming fixes.

Core labels: code, local preview, visual comment, fix UI.

### Variation 2: Comment Pins On The Page

Big idea: show a browser preview with comment pins on a button, heading, spacing, and mobile layout.

Core labels: too small, vague heading, more spacing, mobile broken.

### Variation 3: Browser Use vs In-App Browser

Big idea: compare browsing the web with visually reviewing a local build.

Core labels: web navigation, local preview, visual feedback, UI iteration.
