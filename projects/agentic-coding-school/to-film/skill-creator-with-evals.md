# Skill Creator with Evals

Use the `/skill-creator` skill to build new skills from scratch — and run evals to test whether they actually trigger reliably. The skill interviews you about what you want, generates the skill file, then benchmarks it with variance analysis so you know if it's consistent before you ship it.
