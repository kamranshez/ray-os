## Video 1 — What is Claude CoWork + Installation

**Goal**: Viewer goes from "I've heard of this" to having CoWork installed and open on their screen.

---

### HOOK (0:00–0:30)

> "Claude CoWork just turned your computer into an AI employee. Not a chatbot that gives you answers — an actual agent that can open your apps, organize your files, browse the web, and execute real tasks while you step away. In this video I'm going to show you exactly what it is, how to install it, and get you set up from scratch in under 10 minutes."

---

### SECTION 1: What is Claude CoWork? (0:30–3:00)

**On screen**: Claude desktop app open, CoWork tab visible.

> "So what actually is Claude CoWork? If you've used Claude before — the chatbot where you type a question and get an answer — CoWork is a completely different mode. It's built into the same Claude desktop app, but instead of chatting back and forth, you're delegating tasks."

**Explain the core concept**:
- CoWork can read and write files on your computer
- It can browse the web using your Chrome browser
- It can connect to apps like Gmail, Google Drive, Slack, Calendar
- It creates a plan, shows you the plan, then executes step by step
- It can run tasks in the background while you do other work

> "The key mental shift is this: with regular Claude chat, you're in a conversation. With CoWork, you're giving it a job and walking away. It's task delegation, not conversation."

**Show the three tabs**: Chat | Code | CoWork at the top of the desktop app.

> "You'll see these three tabs at the top. Chat is for questions and brainstorming. Code is for developers who want to write software. CoWork is for everyone — it's the one that can actually take action on your computer."

**Reference from competitors**: Tim explains it as "who it's designed to be used by — CoWork is for beginners, Code is for power users, but they can pretty much do the same thing." Bart frames it as "Claude chat is an assistant who answers questions, Claude Code is a developer who builds software, Claude CoWork is an employee who can complete tasks."

---

### SECTION 2: What You Need (3:00–4:30)

**On screen**: Claude pricing page.

> "Before we install anything, here's what you need."

Walk through requirements:
1. **A paid Claude subscription** — Pro ($20/month) or Max ($100 or $200/month)
   - Pro is fine to start with
   - Max gives you 5x the usage limits
   - CoWork uses significantly more credits than regular chat because it's doing more operations
   - > "Start with Pro. If you're constantly hitting limits, that's your signal to upgrade to Max."
2. **A Mac or Windows computer**
   - CoWork only runs in the desktop app, not in the browser
   - Your computer needs to be on and the app needs to be open for CoWork to work
3. **Google Chrome** (recommended)
   - For browser automation features later

> "One thing that surprises people: CoWork only works when your computer is on and the desktop app is open. It's not running on a server somewhere. If you close your laptop, CoWork stops."

---

### SECTION 3: Installation — Step by Step (4:30–7:00)

**On screen**: Screen recording of the entire process.

**Step 1: Download the desktop app**
- Go to claude.ai/download
- Click the download for your OS (Mac or Windows)
- Show the download happening
- Open the installer, drag to Applications (Mac) or run installer (Windows)

> "Just like installing any other app. Nothing special here."

**Step 2: Open the app and sign in**
- Launch Claude from Applications
- Sign in with your Anthropic account
- Show the main interface loading

**Step 3: Switch to CoWork mode**
- Point out the three tabs at the top: Chat | Code | CoWork
- Click on CoWork
- Show the CoWork interface appearing

> "This is the moment everything changes. You're now in CoWork mode. Notice the interface looks different — you've got this task input area in the center, and a sidebar on the left where your tasks will appear."

**Step 4: Check for updates**
- Click the three lines (hamburger menu) top left
- Go to Help → Check for updates
- > "Always make sure you're on the latest version. Anthropic ships updates frequently and new features drop almost weekly."

**Step 5: Install the Chrome extension (optional but recommended)**
- Open Chrome
- Search "Claude for Chrome extension" or go to Chrome Web Store
- Click "Add to Chrome"
- > "This is what lets CoWork control your browser — open tabs, click things, fill out forms, read pages. We'll use this in a later video but install it now so it's ready."

---

### SECTION 4: Quick Tour of the Interface (7:00–9:00)

**On screen**: CoWork interface with callouts.

Walk through each element:

1. **The task input** (center)
   - > "This is where you type what you want CoWork to do. Think of it like giving instructions to an employee, not asking a question."

2. **Model selector** (bottom)
   - Show Opus 4.6 vs Sonnet 4.6
   - > "Opus is smarter but uses way more credits. Sonnet is faster and cheaper. For most tasks, start with Sonnet. Switch to Opus when you need heavy reasoning."

3. **Folder selector** ("Work in a folder")
   - > "This is how you give CoWork access to files on your computer. It can ONLY touch folders you explicitly allow. We'll set this up properly in the next video."

4. **Left sidebar**
   - Recent tasks / conversations
   - Projects (at the bottom)
   - Scheduled tasks
   - Customize (skills, connectors)

5. **Attachments** (bottom bar)
   - Files, photos, skills, connectors
   - > "You can drag files in, connect apps, and add skills — we'll cover all of this in the course."

6. **Progress bar** (appears when a task is running)
   - Shows what CoWork is currently doing
   - Task list with checkmarks
   - > "When CoWork is working, you'll see a live progress bar. It breaks your request into subtasks and checks them off as it goes. This is how you monitor what it's doing."
