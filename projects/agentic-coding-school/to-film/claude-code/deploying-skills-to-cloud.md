# Deploying Skills to the Cloud (Modal / Netlify)

Take locally-built skills and deploy to the internet. Modal for serverless functions (API endpoints, webhooks). Netlify for static sites.

Demo: sign up Modal ($5 free credits), deploy a birthday-check endpoint accessible via browser. Then deploy lead scraping skill as a web form — fill out form, get CSV. Environment variables in production. Integration with no-code tools (N8N, Make.com) via webhooks.
