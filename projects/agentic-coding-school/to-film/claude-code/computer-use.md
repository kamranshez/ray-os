# Computer Use (Mouse / Keyboard Control)

Claude Desktop's computer use: literally controls mouse and keyboard. Can do ANYTHING on the computer — move files, click menu items, navigate Finder, interact with native apps. Very slow and expensive but universally capable.

The automation gradient: HTTP requests (fast/cheap/fragile) → browser automation (medium) → computer use (slow/expensive/universal). When to use each tier.
