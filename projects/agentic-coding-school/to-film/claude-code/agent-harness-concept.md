# Agent Harness Concept

What is an "agent harness" — the code wrapping around an LLM that turns text-in/text-out into something that controls a computer. Claude Code IS the harness. Includes: system prompt, hooks, tools, parameters, memory.

Analogies: dog sled harness, gun barrel directing gunpowder. Reference Anthropic's Nov 2025 blog "Effective Harnesses for Long-Running Agents." Skills and subagents are both "organized markdown files" — same idea, different shape. Brief comparison to alternatives (Droid, Pi, CrewAI).
