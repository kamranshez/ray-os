# Front-End Design Skill

Create a skill that transforms app UIs with a dramatic before/after. Demo building a front-end design skill that:

1. **Defines design principles** — Typography, spacing, color palette, component patterns
2. **References inspiration** — Attach screenshots or reference URLs for the target aesthetic
3. **Applies holistically** — Skill guides Claude to redesign pages end-to-end, not just individual components

**Key demo:** Take an ugly default app and transform it into a polished UI using just the skill — show the before/after.
