## The one-line direction
Reposition the homepage from "learn the tools / top-1% agentic coder" to **"become an Agent Engineer."** The door is open to everyone (competent to elite), the lead promise is a method — **you learn to engineer loops** — and the identity you earn is Agent Engineer. Calm, confident, respectful tone. NOT IndyDevDan's "evolve or die" doom.

## The spine (the whole page hangs off this)
1. **Villain (universalized, LOCKED):** *"You're still doing by hand what your agents could do for you."* Visceral support image: babysitting one agent in one window, hitting approve, retyping the same prompt. Works whether the visitor is already fluent OR just starting. (This REPLACES the old "you already know Claude Code, leaving 90% on the table" lead, which assumed fluency and clashed with the open door. The "90% on the table" line can still appear lower, aimed at the fluent.)
2. **The fix / the lead = engineer loops.** You learn to build the systems (loops, verifiers, context layers) that make agents write, verify, and ship code on their own. This is the emotional and intellectual lead of the page. It's Ray's brand (Loopy AI, "the loop way of shipping software"), and it's the direct answer to the villain.
3. **The identity = Agent Engineer.** The person who engineers loops. Aspirational, owned (agentengineer.pro).
4. **The reassurance pillar = always-current** (see below). Demoted from "main reason to buy" to the objection-killer.

## Audience & the gate (DECIDED: no gate, inclusive, soft floor)
- **No exclusivity gate.** Hero is inclusive: "go from competent to elite with agents." The elite identity is the DESTINATION, not the entry requirement. This protects the ~1/3 beginner / non-traditional tail that converts and reviews well, and maximizes top-of-funnel.
- **Soft floor (set expectations honestly).** State a baseline plainly somewhere on the page: *"You should be able to write and run basic code. We take you from there, from your first loop to running agent teams."* This filters the truly-unready (refund risk) without gating seniors. Do NOT promise "from absolute zero / no coding needed" unless a real from-scratch track exists in the product (it does not today).
- Because there's no gate, **the price is carried by the method + proof + always-current**, not by exclusivity.

### Personas (priority)
1. **Plateaued Senior — PRIMARY.** Staff/senior/lead, 5–15+ yrs, real software co (N26, AUTO1, commercetools, Trusted Shops, MCG Health in the buyer base). Uses CC/Codex daily, competent, plateaued. Their words: "going from prompting to automated loops." Not price-sensitive.
2. **Solo founder / indie builder.** Wants "one-man unicorn," buys lifetime.
3. **Enterprise team — UNTAPPED B2B lane** (MCG ~60 seats). Supporting band, not the hero (see Team lane).
4. **Non-traditional builder — PROTECT, don't target.** ~1/3 tail, converts + reviews well. The open door + soft floor is exactly for them. "Competent → elite," never "seniors only."

## Identity & naming (nuance, unchanged)
- **Hero identity flag = "Agent Engineer."** Owned, aspirational, no competitor flies it.
- **SEO / `<title>` / meta / schema = "agentic coding / agentic engineering."** ("Agent engineer" as a *search term* points at a different job, people who build agent products, so don't bet SEO on it.)
- Net: hero says **Agent Engineer**; metadata keeps **agentic coding**.

## The definition (LOCKED: the ladder)
On-page definition:
> A developer writes code. A power user prompts an agent to write code. An **agent engineer** builds the system, the loops, verifiers, and context layers, that makes agents write, verify, and ship code on their own.

Hero subhead (software engineer, multiplied):
> An agent engineer is a software engineer multiplied: you stop writing the code and start engineering the system that writes, checks, and ships it, then you run a team of agents in parallel.

(No em/en dashes in rendered copy. Those above are brief-only. Use commas/colons/periods.)

## Always-current (DECIDED: supporting pillar + objection-killer, scoped)
- **Role:** NOT the main reason to buy. It's the answer to "won't this be outdated in a month?" Place it as a trust pillar, not the hero promise.
- **Scope (important honesty):** "always-current" means **the classes you bought keep getting updated and never go stale**, updated many times a week, the day Anthropic ships. It does NOT mean brand-new classes are free, those are separate products. So the claim is "buy this, it never rots," which is true for every buyer with no upsell.
- **Framing vs competitors:** "Most courses are static and months out of date. This one is updated almost every day." This is the structural thing fixed-cohort competitors ($599 IndyDevDan, $995 aihero) cannot match.

## Proof (DECIDED: honest-framed)
- **Ray's 19hr run = labeled as HIS demo, not a student result.** "Here's a 19-hour run I did: it verified ~300 Chrome user flows (241 passed, 66 partial, 16 failing surfaced). Boris (Claude Code's creator) replied 'Nice.' This is what loop engineering makes possible." Screenshot-backed.
- **5–10x = softened to a report, not a guarantee.** "Engineers running real loops report shipping several times more than they used to." Do NOT state "ship 5-10x, period" as a measured student outcome.
- **Testimonials = verbatim, qualitative.** Copy-ready language: "from treating Claude Code like a chatbot to a full development platform," "thinking in it," "the advanced version," "5% only know," "level up," "updated almost every day." On-page testimonial IDs (real, reusable): tyler, divyansh, bernard, simeon.
- **Scale proof:** 3,151 students; an anonymized ~60-seat healthcare-tech rollout.
- **Honesty caveats:** Loopy AI still partly in production; content is Claude-centric; the 19hr run is Ray's. Don't overclaim.

## Offer & pricing (DECIDED: one all-access pass, no expansion tier)
- **Individual = one clean all-access pass** to everything in the school today: keep the existing **monthly / yearly / lifetime**. Every tier includes all current classes, kept current forever.
- **DROP the +$150–200 "expansion / Agentic Horizon" tier.** Its rationale was "updates are the upgrade," which is dead now that updates are free with the class. No invented upsell.
- **Future classes = separate products**, not bundled into lifetime/sub (consistent with existing pricing policy).
- **Price:** $397-ish current anchor → ~$500 once elite content (Loopy AI etc.) fully shipped. Raise trigger still open (see open-decisions).
- **Team = a B2B lane** (see below), billed by seats / invoice. A Team Stripe product already exists.

## Team lane (DECIDED: visible band, secondary, NOT a dual-path hero)
- Individual is the hero and the whole page's spine; individuals are ~82% of sales today, don't dilute that.
- **Mid-page team band:** "Bringing agents to your whole team? Volume seats, invoice billing, one rollout." CTA = **"Talk to us"** (not self-serve checkout). Include the anonymized 60-seat rollout as proof.
- **What the curriculum HONESTLY backs for teams:** (1) "Raise your whole team's floor" (Context Engineering: shared CLAUDE.md/AGENTS.md + skills so juniors output at senior level). (2) "Multiply every engineer's throughput" (multi-agent orchestration). Frame as *each engineer ships several times more*, not "manage your people." SUPPORT: fast onboarding lesson; governance/skills-as-code (sell the concept, ~2 videos). PHRASE CAREFULLY: "the context layer and skills you build survive model upgrades," NOT "there's a future-proofing course." DO NOT use the For-Business class.

## The wedge vs competitors
Lead the differentiation with **the loop method (most complete system, not a one-trick workshop)** backed by **always-current** and **honest receipts** (3,151 students, the 19hr/Boris demo, the 60-seat rollout). Beat IndyDevDan on: a calmer respectful tone vs his doom; team/seats (he has none); always-current vs his filmed-once cohort; a thicker honest proof wall. Borrow nothing that requires the dead expansion tier.
