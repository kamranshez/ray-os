# positioning/ — the hub

Single home for **who we sell to, what we decided, and why.** Everything downstream (the landing variations in `../landing/`, the VSL in `../vsl/`) consumes this folder. Read this before writing or revising landing copy, VSL scripts, ads, or pricing, instead of re-deriving the audience.

## Contents
- **`brief.md`** — THE source of truth. The locked positioning for the "Agent Engineer" reposition: identity, villain, definition, personas, pricing/offer architecture, team offer, proof assets, tone guardrails, and the spec for the 5 landing variations. Start here.
- **`open-decisions.md`** — what still needs Ray's confirmation (split path, PPP, naming the 60-seat customer, price-raise timing) vs what's locked.
- **`research/`** — the 6-source market analysis this is all built on (newsletter survey, buyer DB, customer enrichment, Gmail testimonials, course content, competitor/naming, YouTube). `research/README.md` indexes it; `research/00-synthesis-personas-positioning.md` is the personas + full decision trail. Append new data here rather than redoing it.

## How to use (for an agent picking this up cold)
1. Read `brief.md` end to end.
2. Skim `research/00-synthesis-personas-positioning.md` for the personas + evidence.
3. Check `open-decisions.md` so you don't hard-code something still under debate.
4. Then go build the deliverable in `../landing/` or `../vsl/`.
