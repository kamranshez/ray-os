## The Customizer Pattern

A meta-skill that customizes other skills to your preferences.

### Core Concept

Download someone's skill → run /customize → answer questions about your brand/preferences → get a personalized version.

From Brock's video: "This skill will help you customize any of these different skills in co-work so it adds your context, edits the instructions so it's specified to you."

### What to Show

1. Take any skill from the class (or a marketplace skill)
2. Invoke the customizer: `/customize`
3. It asks questions: "What skill do you want to customize? What's most important to customize? What's your visual vibe?"
4. "I basically said I want the visual vibe to be more of a Swiss style design. And just like that, it generated this version — more of a Swiss design with white, black, and red accents." (Brock)
5. Show before/after: generic slide deck skill → Swiss-design-branded version with your colors

### Why This Matters for Sharing

"Throughout this video, you're going to notice that some of these skills are tailored towards me and my business. Well, this skill will help you customize any of these skills so they function perfectly for your use cases." (Brock)

You can share one plugin with your team and each person customizes it to their context. One skill, many personalized versions.

### Connection to Ch 3

The customizer pattern is a lighter-weight version of Ch 3's brand context approach. Ch 3 = systematic (shared reference files). Customizer = quick and targeted (one skill at a time).
