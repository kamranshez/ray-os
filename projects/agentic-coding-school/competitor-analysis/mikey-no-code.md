## Gaps Not Covered in Master Claude Code

- **[MEDIUM] Building a React Native + Expo mobile app with Claude Code (end-to-end)** — Mikey builds a complete mobile app (math homework helper) using React Native with Expo SDK 54. The workflow covers: creating the project scaffold, building 5 mobile-optimized sections (dashboard, saved, learn, quiz, settings), adding camera/upload widgets, integrating OpenAI for image-to-math-solution, save functionality, and a learn/quiz section. Ray's course covers web app building but may not have a dedicated mobile app (React Native/Expo) example.

- **[MEDIUM] OpenAI API integration inside a Claude Code-built app** — Mikey integrates OpenAI's vision API to process uploaded math problem images and return step-by-step solutions. The prompt includes specific instructions for .env file creation, .gitignore setup, and never hardcoding API keys. This shows Claude Code building an app that itself uses another AI API, which is a practical pattern.

- **[LOW] Cloning a revenue-generating App Store app as a project idea framework** — Mikey starts by identifying a $400K/month app (Question AI) on the App Store, analyzing its features, and then building a clone. This "find a successful app -> clone it with Claude Code" framework is a business-oriented approach not covered in Ray's course.

- **[LOW] Claude Code VS Code extension install path (not terminal CLI)** — Mikey installs Claude Code through the VS Code extensions marketplace rather than the terminal npm install. This is an alternative installation method.

- **[LOW] Progressive feature building pattern with iterative prompts** — Mikey demonstrates building an app feature-by-feature with separate prompts for each: (1) front-end scaffold, (2) upload/camera widget, (3) AI integration, (4) save functionality, (5) learn section, (6) quiz section. Each prompt builds on the previous state. While Ray covers planning, this specific step-by-step prompting pattern for feature layering is shown concretely.
