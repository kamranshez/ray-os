## Gaps Ray's Course Does Not Cover

### Ralph Claude Loop: Infinite Autonomous Coding Agent [HIGH]

Julian demonstrates "Ralph" -- a third-party tool that wraps Claude Code in an infinite loop with a prompt.md file, letting it autonomously build/test/fix a project overnight without human intervention. Includes tmux-based monitoring dashboard, retry limits, and completion signals.

> "Ralph Claude loop is a plug-in for Claude that turns it into a non-stop AI worker. Instead of generating code once and stopping, Claude will just keep going until the task is actually complete, fixing bugs, testing code automatically"

Ray does not cover Ralph or any infinite-loop autonomous agent wrapper. This is a power-user pattern for overnight builds.

---

### Vibe Kanban: Multi-Agent Task Board [HIGH]

Julian demonstrates Vibe Kanban -- a tool that provides a Kanban board UI for managing multiple Claude Code agents in parallel. Each task card gets its own agent, with a diff tool for reviewing completed work.

> "You can set up multiple tasks. Each task gets its own coding agent, and they all work at the same time. While they're coding in the background, you're doing the high-level stuff."

Key workflow: create task cards, assign to agents, agents work in parallel, review via diff tool, approve or send back. This is a project management layer on top of Claude Code.

Ray does not cover Vibe Kanban or any multi-agent orchestration UI.

---

While this is Claude.ai (not Claude Code), the concept of persistent project templates for recurring tasks is transferable. Ray's course could show the Claude Code equivalent using skills + CLAUDE.md for the same pattern.

### Twitter/X "Greatest Hits" Rewriting System [MEDIUM]

Julian builds a system for X/Twitter content:
1. Track all tweets in a spreadsheet (date, text, views, hook)
2. Identify top 10% and bottom 90% by performance
3. Feed winning patterns + losing patterns into a Claude Project
4. Generate new tweets that follow winning patterns and avoid losers
5. Iterate daily, adding new data

> "We're going to tell Claude to do more of this... and then over here, you can see these are our worst performing hooks and we want to avoid these"

This data-driven content optimization loop is not covered in Ray's course.
