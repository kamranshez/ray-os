## Gaps Not Covered in Master Claude Code

- **[HIGH] Non-technical / non-coding use cases as the primary framing**: Allie's entire video is aimed at non-engineers using Claude Code for file management, data analysis, creating presentations, managing system resources, and document conversion. Ray's course is code-focused. Specific examples Allie covers that Ray doesn't:
  - Creating Word docs (.docx) from text files and converting between file types
  - Creating CSV files with synthetic data, then building interactive HTML dashboards from that data
  - Turning dashboards into click-through presentation-style HTML with left/right navigation
  - Creating "McKinsey-style" presentations from data
  - Turning a photo of a Walmart receipt into a structured expense report using OCR
  - Checking Activity Monitor to find resource-hogging apps ("What is stealing the most?")
  - Finding and suggesting large files to delete to free disk space
  - Downscaling/compressing images via natural language

- **[MEDIUM] Running multiple terminals as "six interns"**: Allie describes opening six terminal windows, each with Claude Code running, and assigning different tasks to each -- likening it to "having six interns." Quote: "I could have multiple terminals running... it's like having six interns." Ray covers parallel work but not with this non-technical framing.

- **[MEDIUM] Queuing up prompts while Claude is still working**: Allie demonstrates typing the next prompt and hitting Enter before Claude finishes the current task, so it queues up automatically. Quote: "I hit enter on that before the first ask was finished. So you can see that because I already hit enter, it queued up that next prompt." Ray doesn't have a specific video on prompt queuing behavior.

- **[LOW] Copying terminal output to Claude.ai or ChatGPT when stuck**: Allie's "last hack" is to highlight the entire terminal conversation, copy it, paste it into Claude.ai or ChatGPT, and ask for help understanding errors. Quote: "You can just highlight the entire terminal conversation... paste it and go 'What the heck's going on?'" This is a simple but practical tip Ray doesn't cover.

- **[LOW] Explaining terminal commands to absolute beginners**: Allie explains what curl, pipe, bash, mkdir, and cd mean for people who have never used a terminal. Ray covers terminal commands but not at this truly beginner level of explaining what a pipe character does.

Note: Most of Allie's video covers ground Ray already addresses (installation, permissions, /clear, plan mode, thinking toggle, creating agents/skills). The main gap is the non-technical use case framing -- Claude Code as a general-purpose computer assistant rather than a coding tool.
