# Voice and copy rules

Every output (landing copy, VSL, ads, emails) must follow these. The "why" is in `positioning/brief.md`; this is the quick-reference checklist.

## Hard rules
- **No em dashes (—) or en dashes (–) in any user-facing copy.** Use commas, periods, or colons.
- **Mark any invented stat as `[placeholder]`** so it is never mistaken for real data.
- **Brand accent: emerald `#10b981`** (matches the live theme color). Clean, premium, lots of whitespace.

## Tone
- Confident and respectful. **NOT** IndyDevDan's "evolve or die / Codebase Singularity" doom. The senior audience repels from fear; name the plateau, then offer the level up.
- Calm and premium, not garish or hypey.
- Inclusive: "competent to elite," door open to everyone. Never "seniors only."

## Identity and naming
- **Hero identity flag = "Agent Engineer."** Aspirational, owned (agentengineer.pro).
- **SEO / `<title>` / meta / schema = "agentic coding / agentic engineering."** ("Agent engineer" as a search term points at a different job, so don't bet SEO on it.)

## Locked lines (use verbatim or close)
- **Villain (universal):** "You're still doing by hand what your agents could do for you." Visceral support image: babysitting one agent in one window, hitting approve, retyping the same prompt.
- **The fix / lead:** you learn to **engineer loops**, the systems (loops, verifiers, context layers) that make agents write, verify, and ship code on their own.
- **The ladder (definition):** "A developer writes code. A power user prompts an agent to write code. An agent engineer builds the system, the loops, verifiers, and context layers, that makes agents write, verify, and ship code on their own."
- **Soft floor (set expectations):** "You should be able to write and run basic code. We take you from there, from your first loop to running agent teams."

## Honesty guardrails (the proof line)
- The 19-hour / ~300-flow run with Boris's "Nice" is **Ray's own demo** ("what loop engineering makes possible"), NOT a student result. Label it as such.
- The 5-10x figure is **"students report shipping several times more,"** not a measured guarantee. Do not state "ship 5-10x, period" as a typical outcome.
- **Anonymize the 60-seat customer (MCG Health)** as "a 60-engineer healthcare-tech org" until they consent to be named.
- Always-current means the classes you bought stay updated, not that new classes are free.
