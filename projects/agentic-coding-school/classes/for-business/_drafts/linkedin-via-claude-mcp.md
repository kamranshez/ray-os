# LinkedIn via Claude MCP

Connect Claude Code to LinkedIn using an MCP server to automate your LinkedIn presence:

1. **MCP setup** — Configure a LinkedIn MCP server (or browser automation MCP) to read/write LinkedIn
2. **Post generation** — Use a brand voice skill + Claude to draft LinkedIn posts from your content pillars
3. **Engagement research** — Analyze what's performing in your niche before posting
4. **Publishing workflow** — Review drafts, approve, and publish directly from Claude Code

**Key demo:** Go from idea to published LinkedIn post without leaving the terminal.
