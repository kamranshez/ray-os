"More agents" used to mean "more mess."

Every subagent you spawned reported back to your main Claude Code session. That session held every result, every handoff, every intermediate output. By agent 10 it was bloated. By agent 20 it was forgetting things and getting sloppy.

So you capped yourself. Three agents, maybe five. Past that it fell apart.

Anthropic just shipped Dynamic Workflows. It removes the model from orchestration entirely.

Now a JavaScript file is the orchestrator. Results pass directly from one agent to the next. They never touch your main context.

Which flips the whole thing. 10 agents or 100, the orchestrator stays clean.

The ceiling on multi-agent work was never the agents. It was the thing coordinating them.

That ceiling is gone.
