Claude Code just got a new planning mode that runs in the cloud.

It's called Ultraplan. You type /ultraplan, describe what you want to build, and it hands the planning off to a web session while your terminal stays free.

You get a proper review UI. Inline comments. Emoji reactions. An outline sidebar. It's closer to reviewing a Google Doc than reading terminal output.

When the plan is ready you get two choices:
→ Run it in the cloud and it opens a PR when done
→ Teleport it back to your terminal and implement locally

In my testing it was about 2x faster than local planning. And because your terminal stays free, you can keep coding while it thinks.

But I noticed something odd about the quality. Sometimes brilliant. Sometimes mid. Same prompt, different results.

So I dug into the binary and found something Anthropic isn't telling you.
