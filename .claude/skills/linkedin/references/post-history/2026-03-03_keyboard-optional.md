Claude Code just made your keyboard optional.

Hold spacebar. Describe what you want built. Let go. That's it.

We're watching the input layer for coding get thinner all year. First we stopped writing code and started writing prompts about code. Now we're not even typing the prompts.

Best take I saw: "The slow part was never typing. It's knowing what to build. Voice just means you can be unclear out loud now."

When I type a prompt, I edit it. I restructure. I second-guess the wording. When I talk, I just explain the problem like I'm pairing with a colleague. Less polished, but more honest about what I actually need.

Combine this with remote control (which shipped last week) and you can dictate code changes from your phone while walking your dog.

The keyboard becoming optional faster than anyone expected.
