## Key Patterns

### 1. Dark backgrounds dominate (12/15)
Almost every thumbnail uses a dark/black background. This makes text and icons pop, especially on mobile.

### 2. Orange is the universal accent color
Claude's brand orange appears in nearly every thumbnail. It's become the visual shorthand for "Claude content."

### 3. Face vs No-Face split
- 5/15 use faces, 10/15 are text/icon only
- **BUT** the top face-based thumbnails (Alex Ziskind 118.5k, Nick Saraev 110.8k, DevOps Toolbox 108.3k) all outperformed most no-face ones
- Face thumbnails that work: person holding laptop/screen showing a specific result or tool
- Expression: serious/curious/intrigued — NOT exaggerated shock

### 4. Bold short text wins
Best performers use 1-2 word power phrases: "UNSTOPPABLE", "99% SAVINGS", "SELF-IMPROVING", "AI RUNS MY LIFE"

### 5. Numbers and specifics drive clicks
"1,000,000 Tokens", "99% Savings", "$0.10" — concrete numbers create instant curiosity

### 6. The "face + prop" formula
The highest-performing face thumbnails all follow: Person + physical prop (laptop/receipt) showing a specific result/number

## Recommendations for Ray's Thumbnail

Ray's current thumbnail ("It's Finally Coming!") uses:
- Face with mild concern/intrigue expression ✓
- Software Factory diagram + Claude Code terminals
- Red banner text at bottom

**What could improve:**
1. **Simplify** — too many elements (diagram + 2 terminals + face + text). Hard to parse at small mobile size
2. **Bolder text** — "It's Finally Coming!" is 3 words but the red banner is small relative to the frame
3. **Consider dark background** — every competitor uses dark bg; the white/light bg is actually differentiating but may not pop on YouTube's UI
4. **Add a number or specific hook** if the content supports it
5. **Face expression** could be more intense — the current expression is subtle
