# Report + picker formats

## Report (markdown, no H1, no em/en dashes)

```
---
tags: [youtube-miner, ideas, research, <creator-slug>]
aliases: [<Creator> Insight Mine]
date: YYYY-MM-DD
source: "<Creator> channel, <window>"
---

> Auto-generated by youtube-miner on YYYY-MM-DD. Scanned N videos, M above the bar,
> K transcript-mined into J candidate insights. P relevant videos were metadata-only.

## Summary
What was scanned and the headline opportunities. Name the recurring veins.

## Top ideas
Ranked, best first. For each:
- A bold suggested title.
- The core insight (2-3 sentences).
- Original source: name + link (the blog/paper/tweet the creator was reacting to).
- Audience is asking for: what the comments show people want or struggle with here.
- Relates to: how it extends / contrasts / sequels existing work (if a curriculum was checked).
- The creator's video: title + link.

## What the audience keeps asking for
Cross-video synthesis of the strongest demand signals from comments. These are proven-interest
topics even when no single video nails them.

## Recurring themes
Patterns across the catalogue worth a multi-part series rather than one-offs.

## Coverage and caveats
Videos discovered / above bar / mined / dropped (metadata only). Whether ranking used view data.
Any insights with no external source (still usable, but they lack the source-traceable property).
```

Rank by a blend of (a) novelty / counter-intuitiveness and (b) how cleanly the idea traces to an
interesting original source you can cite and walk through. An idea that is "creator's own take" with
no external source is still worth listing, but flag it so the user can prioritize the sourced ones.

## Picker JSON (input to `scripts/build_picker.py`)

```json
{
  "title": "Theo Insight Mine - pick the ideas worth filming",
  "subtitle": "246 videos scanned, 80 mined. Tick what interests you, then Copy selection.",
  "sections": [
    {
      "name": "Top ideas (source-traceable, ranked)",
      "items": [
        {
          "label": "#1",
          "title": "Delete Your CLAUDE.md (The Peer-Reviewed Case)",
          "desc": "ICML paper: generated AGENTS.md/CLAUDE.md reduce SWE-bench success and inflate cost.",
          "tags": [{"text": "top", "kind": "hot"}],
          "links": [
            {"text": "Gloaguen et al. (ICML 2026)", "url": "https://arxiv.org/abs/...", "kind": "src"},
            {"text": "Theo video", "url": "https://www.youtube.com/watch?v=...", "kind": "yt"}
          ]
        }
      ]
    }
  ]
}
```

- `kind` on a link: `src` (green, original source) or `yt` (red, the creator's video).
- `kind` on a tag: `hot` (amber), `seq` (blue, e.g. "sequel to existing video"), or omitted (grey).
- The builder makes link chips clickable WITHOUT toggling the card, auto-fills the copy box with the
  ticked items, and strips em/en dashes. Don't reimplement it.

When the heavy Workflow engine runs, its synthesis stage already returns this picker object, so you
can write it straight to a JSON file and run the builder.
