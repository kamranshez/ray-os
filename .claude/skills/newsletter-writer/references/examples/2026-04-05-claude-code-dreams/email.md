I follow the changelog pretty aggressively and there was no mention of anything like this anywhere. So I got Claude Code to inspect its own binary... and it turns out there's a secret new feature that Anthropic hasn't announced yet.

It's called Auto Dream.

Here's the short version. Claude Code already had an auto memory system (since Feb 26, v2.1.59) - it could write notes for itself about your projects and preferences. But the problem was that over time, those memories got noisy. Contradictions, stale notes, irrelevant stuff piling up. By Session 20, I found the memory was actually making the agent perform worse.

Auto Dream fixes this by doing what your brain does when you sleep. It consolidates. It reviews your session history and project, figures out what's still relevant, resolves contradictions, and prunes the stale stuff - all in the background while you keep working.

The human analogy is honestly what makes it click. People who don't sleep enough can't form long-term memories. Their short-term memory fills up and they start confusing things. Claude Code, until now, was basically sleep-deprived in a sense.

I dug into the system prompts, triggered it on my own project (it reviewed 913 sessions), and broke down exactly how it works in a new video.
