# Viral X Article Style Playbook (AI / Coding Niche)

Four DISTINCT molds for long-form X articles that went viral in the AI/Claude Code niche
(April–June 2026). Pick ONE per article. Do not blend them — each travels for a different reason.

Swipe-file source: YouMind viral-X-articles tracker (youmind.com/landing/x-viral-articles/) —
live, sortable feed with real engagement metrics. Refresh this playbook from it periodically.

---

## Archetype A — The Numbered Arsenal

The highest bookmark-rate format. The article literally IS the deliverable.

- **Hook pattern:** A count + a forgetting/secrecy frame, often opening on a relatable failure.
  - "8 Claude Code Hooks That Automate What You Keep Forgetting" (1M+ views)
  - "The 10 Claude Code agents nobody told you to build" (1.2M)
  - "30 Copy-Paste System Prompts That Make Claude an Expert at Anything" (607K)
  - Cold open example: "You said format the code — it didn't. You said run tests — it forgot."
- **Structure:** short mechanism primer (30 sec) → N self-contained copy-paste items
  (Problem → asset/code → one-line payoff) → "start with these 2–3" de-overwhelm closer →
  a combined "copy this whole file" block.
- **Pacing:** fast, scannable, each item ~80–150 words. Reader can stop anywhere and still win.
- **Use when:** you have concrete reusable assets (configs, prompts, agent definitions).
  People save it to USE later. Best for "here are the tools" content.

## Archetype B — The Opinionated Showdown (Comparison + Verdict)

Travels by resolving a debate the reader is already having in their head.

- **Hook pattern:** name the two rivals everyone argues about + promise to settle it.
  - "Claude Code vs. Codex: The Definitive Guide" (603K)
  - "Claude Code vs. Codex: The Ultimate Guide to Choosing the Right AI Agent" (734K)
- **Structure:** fixed criteria grid (~5 dimensions) → honest "X wins here / Y wins there" →
  per-use-case VERDICT → "use both, here's how to route work" reconciliation.
- **Pacing:** even, table-driven, builds to a decision.
- **Use when:** there's a live either/or in the audience (Claude vs Codex, RAG vs long-context,
  vibe vs agentic). Lower bookmark ratio than A, high reposts — people share it as their position.

## Archetype C — The Teardown / Leak ("I read it so you don't have to")

Sells on voyeurism + authority-by-proximity. Strong saves: reader feels they hold scarce knowledge.

- **Hook pattern:** a privileged artifact + a labor-saving promise.
  - "Inside the Claude Fable 5 System Prompt: 9 Lessons From the 120K-Character Leak" (700K+)
  - "6 patterns and 14 steps Anthropic engineers actually use" (1.5M)
  - "Lessons from Building Claude Code: How We Use Skills" (6.9M, 44K bookmarks — largest in set)
- **Structure:** the event/source → quantified anatomy (byte-budget table, "5 layers", "27 events")
  → a few money-quote excerpts → N transferable lessons → "what this means for your setup."
- **Pacing:** investigative. Front-load the spectacle, back-load the actionable lessons.
- **Use when:** you have insider / extracted / exhaustive material others can't easily get.

## Archetype D — The Proof-Driven Transformation ("I did X, here's the exact setup")

The metric is the hook; the layered system is the payoff. Converts via proof + low-effort on-ramp.

- **Hook pattern:** first-person result with a hard before→after metric + a parenthetical
  objection-killer.
  - "How I Cut Codex Tokens from 245M to 28M Per Day For Free (Same Speed)" (172K)
  - "How to Make Claude Code Stop Making Stuff Up... (Exact Setup Inside)" (346K)
  - "Build a Software Factory with Claude Code That Ships Features While You Sleep" (2.8M)
- **Structure:** state the result → why it matters → the NAMED layered system
  (Layer 1–4 / Stage 1–4 / a 7-agent pipeline) → time-boxed quick-start ("5-minute setup").
- **Pacing:** tight, momentum toward "you can do this in 5 minutes."
- **Use when:** you have a personal result or repeatable system with a number attached.

## The viral grammar (shows up in EVERY archetype)

1. **A number in the title** — item count (8, 10, 30), a metric (245M→28M, 80%, 120K chars),
   or a layer count (4 layers, 6 patterns + 14 steps).
2. **A parenthetical objection-killer / curiosity gap** — "(Exact Setup Inside)",
   "(For Free, Same Speed)", "(FULL GUIDE)".
3. **A "do this first" closer** that defuses overwhelm — "set up #1 and #2 today",
   "which 5 should you start with".
4. **Copy-paste deliverables in-body** — the article IS the asset (settings.json, prompt blocks,
   agent .md files). This drives the outsized bookmark counts that signal X virality.
5. **Authority borrow** — "what Anthropic engineers actually use", "how we build it",
   a named leaker/engineer (Pliny, Karpathy, Boris Cherny).
