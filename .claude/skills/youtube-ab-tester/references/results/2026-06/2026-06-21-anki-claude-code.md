### Banked rules from R1

1. **On personal-workflow / method videos, first-person ownership beats third-party credential.** "Top 1% Learners" (third-party, 27.6%) lost to "My Setup" (33.9%) and "Changed My Life" (38.4%). The credential frame's strength is specific to feature/technique videos; do not transplant it onto "how I personally do X" videos.
2. **Emotional life-change stakes + a self-aware hedge can top a clean outcome claim.** "Changed My Life (Seriously...)" > "Makes Forgetting Impossible" by 4.5pp. Stakes language is not automatically hype-penalized when paired with a disarming aside.

### Recommendation after R1

Title testing is working (10.8pp spread), so stay on titles for R2. Suggested R2 slate, same thumbnail:
- **Control:** "This Claude Code Setup Changed My Life (Seriously...)" (verbatim winner)
- **Isolate the parenthetical:** "This Claude Code Setup Completely Changed How I Learn" (stakes without the "(Seriously...)" hedge — tests whether the aside or the stakes carried it)
- **Push first-person + concrete benefit:** "How I Use Claude Code to Never Forget Anything I Learn" (personal-workflow, outcome-led — keeps the winning first-person frame, swaps emotional stakes for a concrete never-forget payoff)

Avoid re-running any third-party credential / "Top 1%" / "best learners" arm — that frame is now 0/1 and lost by the widest margin on this video class.
