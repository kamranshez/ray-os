# LinkedIn

Feed analysis, viral post research, and engagement pattern studies now live inside the skill, at
`.claude/skills/linkedin/references/analysis/`, so the research sits next to the template it feeds.

Everything LinkedIn is in `.claude/skills/linkedin/`:

- `references/viral-playbook.md` — the Stanislav skeleton, the single format every post uses
- `references/post-gate.md` — the pre-post checklist, shared with the daily cloud routine
- `references/analysis/` — source-system notes and raw feed captures
- `references/post-history/` — one file per post, with engagement data
